# CHR experimental investigation

The objective is evidence that supports architecture and language-design decisions through total efficiency and necessary implementation complexity. The authoritative future work-selection contract is [the sequence](../../experiments/sequence.md); the [coverage map](../../experiments/coverage.md) records questions, evidence and dispositions.

Current authorization covers redesigning the research program. Experimental implementation and runs are stopped until the owner authorizes resumption. The first eligible research task is R00, which selects discriminating comparisons; unfinished prototypes and report follow-ups have no automatic execution priority.

Once execution is authorized, investigate independent meaningful questions through implementation, experiments, analysis and authoritative sources. Preserve reference independence, prospective comparative registrations, credible controls, adverse outcomes and reproducible evidence. Adoption of experimental language changes or a production architecture requires the owner's decision.

Completion requires an evidence-backed architectural comparison and a question-by-question assessment of remaining uncertainty and the likely value of further investigation relative to its cost. A feasible task is not necessarily worthwhile; a feasible task that can materially improve the architectural decision must not be deferred merely because another candidate is mature or difficult. Readiness, a completed matrix, a timeout or an administrative limit alone does not establish completion.

The PM state records active execution authority and task ownership. It does not supply an alternative experimental ordering to the sequence. Completed package receipts remain valid within their stated limits; unselected leads are tracked in the coverage map.
