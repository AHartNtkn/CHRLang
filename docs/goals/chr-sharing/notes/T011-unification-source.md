# Scalar unification foundation

The conditional-kernel argument uses ordinary finite-tree unification as its scalar reference. The conditional construction is original project analysis, not a result attributed to this paper.

On 2026-09-06, inspected Martelli and Montanari, *An Efficient Unification Algorithm*, TOPLAS 4(2), 1982, pp.258–282, [primary paper via university-hosted copy](https://courses.grainger.illinois.edu/cs576/sp2017/readings/01-jan-19/martelli-montanari-unif.pdf). The relevant evidence is §2, equation transformations, solved forms, Algorithm 1 and Theorems 2.1–2.3. These establish preservation of unifiers, finite-term occurs failure and termination/correctness of the scalar algorithm. No runtime performance result is transferred to conditional CHR.
