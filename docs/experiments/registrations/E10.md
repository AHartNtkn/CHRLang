# E10 — structural operations and constrained term spaces

The first structural-solver implementation must distinguish three boundaries: an exact closed source operation, a regular-language membership fact, and an explicitly generated correlated term space. None substitutes for the others automatically.

## Source clarification used for implementation

The ECTA paper's intersection combines compatible transitions and their path constraints. Dynamic reduction postpones constrained selections through shared variables and refines their spaces. Its cyclic treatment isolates a constrained finite prefix from unconstrained recursion. These observations support a finite-skeleton implementation over regular recursive domains; they do not justify arbitrary recursively generated equality constraints or host resource rewriting. [Koppel et al., §§3.4–5.2](https://arxiv.org/pdf/2206.07828).

For simple repeated holes, explicit logical-variable sharing plus regular intersection is already a competent control. Comparing only against independently choosing both children and rejecting unequal pairs would overstate what an ECTA representation adds. Any such rejection enumerator must be labelled an ablation, with the shared-hole control retained.

## First operation probe

Implement the closed no_c theory on finite acyclic shared constructor data. Direct traversal and exact operation memoization use identical input representation and preserve the normal residual occurrence multiset. k and s succeed, c(_) fails, a(X,Y) creates both obligations, and variables or unknown constructors stay residual. Repeated residual occurrences remain repeated. Memoization keys include the complete frozen input identity; no mutable binding environment is silently ignored.

Compare against independently derived observations and the reference interpreter on bounded trees. Include repeated ground subtrees, repeated unknown holes, failure, extra constructors and multiple occurrences. The repeated unknown-hole case must charge output expansion even when recursive proof work is memoized. A newly linked observer/consumer of no_c invalidates the closed-region shortcut. Snapshot reduction is not a subscription/wake-up implementation; later bindings require fresh validated inputs or an explicit integration protocol.

## Constrained-space probe to accompany it

Implement regular recursive SK domains and exact intersections, then finite constructor skeletons whose repeated holes have explicit equality. Preserve partial answers as existing variables plus their original residual restrictions where expressible. Ground enumeration must correspond to an explicit registered source generator; an automaton union does not create implicit CHR alternatives.

Compare a direct shared-hole/regular-membership control with constrained-space construction and enumeration. Include independent versus repeated holes, intersected domain restrictions, disjoint intersections and a nontrivial finite prefix. Account for construction, intersection, representative merging, enumeration and complete output materialization. A result on simple holes cannot close arbitrary finite path constraints, static reduction or full ECTA compilation.

Before either comparative run, freeze the exact input generators, resource bounds, controls and counter predictions. The broader E10 obligations remain live: lambda normal/neutral/name/disequality interpretations, exact formula projection with existential variables, closure/interface validation, infinite-domain correctness beyond bounded enumeration, and intended synthesis workloads. They are not blocked by this first implementation and must be revisited in the portfolio follow-ups.

## E10a v1 frozen operation matrix

Run shapes ground, hole, unknown, failure and unshared at depths {0,1,4,8,12} and repeated roots {1,8,64}, in Direct and Memo modes: 75 cases × two modes = 150 runs, plus full replay. One fresh release process per case/mode, 60-second bound. These finite traversals have no search-step cutoff. The source/reference checks cover 3,192 bounded input trees in both modes, plus explicit residual multiplicity, external observation and work-sharing checks.

For the first four shapes, each level is a(shared_child,shared_child), and repeated roots reference that same graph. Ground leaves are k, unknown leaves are unknown(c(z)), hole leaves are an unbound variable, and failure leaves are c(z). Unshared constructs every binary-tree node and every repeated root separately, using ground k leaves. No input hash-consing is silently credited to memoization.

For successful shared inputs, Direct computes r*(2^(d+1)−1) operations; Memo computes d+1. For unshared ground inputs both compute r*(2^(d+1)−1), with no memo hits. Failure short-circuits down the first left spine, so both compute d+1 and skip remaining roots. Hole and unknown inputs retain exactly r*2^d residual occurrences; ground inputs retain none. These are closed-operation visits, not ordinary CHR Apply counts.

The memo retains each input key strongly, preventing address reuse while an identity-keyed entry exists. Residual reference transfers count memo cloning and vector extension, not constant-cost calls. Allocation phases separately charge input/certificate construction, reduction and full residual export. Export retains output aliases and every residual occurrence. Baseline/peak/final payload and timing are recorded; timing is diagnostic. The unknown(c(z)) case must remain residual, demonstrating the difference from closed SK membership.

## Regular and skeleton validation boundary

Regular intersection uses reachable state pairs; productivity computes a least fixed point. The implementation's witness construction is sound because every constructed node has previously constructed finite children. Completeness follows by induction on finite derivation height; an unproductive cycle alone supplies no finite witness. Membership descends a finite input tree; pair-state intersection correctness follows by induction on that tree. Size-stratified enumeration uses positive child sizes smaller than the parent. These are algorithm arguments, not kernel-checked proofs.

The skeleton implementation currently supports equality between named leaf holes, repeated occurrences and conjunctions of regular restrictions. It eagerly materializes hole domains at a registered node bound, then enumerates products incrementally. This is a restricted bounded constrained-space probe, not an implementation of arbitrary ECTA path constraints or lazy unbounded dynamic reduction. Both filter controls unify equal holes before enumeration; all modes share identical-domain candidate lists without making independent holes equal. Formula projection of unreferenced existential classes is outside this interface.
