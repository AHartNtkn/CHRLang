# User-program compilation and observed amortization

Registered before emission, compilation or comparative runs. Reuse the existing
emitter, shared libraries and qualified long-session runner. No new executor.

Four source regimes are frozen: (family1, depth128, repeated); (family2, depth128,
four-query cycle); (family3, depth32, four-query cycle); and the adverse shallow
control (family0, depth4, repeated). All exhaust and immediately dispose outputs.
These span promising inferred-generated cases from the preceding diagnostic and
an overhead control. Initial reuse counts are64 and8192. Seven modes remain:
trace, Direct, scan, indexed, inferred, generated and generated-inferred.

Build shared ordinary and allocation-meter libraries offline with two Cargo jobs;
record this separately as tool/dependency construction. Emit one forward user
program per artifact, never query values. Emit an equivalent generic wrapper as
a compiler/link control. Compile five ordinary copies of each generic/generated
family and one metered copy, using rustc edition2024, opt-level3, codegen-units1,
lto=off and the same frozen shared libraries. Randomize the eight family/type
combinations within each ordinary compiler repetition with seed607098. Record
emission, source-file writing, buffer disposal, compilation wall/CPU costs,
source/binary sizes and hashes. Validate each artifact on its actual family.

Before timing, run all56 initial cells twice with the allocation meter and once
ordinary for source/ownership qualification. Require complete per-query counts,
independently checked oracle classes, consumer equivalence, phase continuity,
exact repeated ownership and root restoration. Then run five timing blocks,
randomizing the eight scenarios and seven mode orders within each scenario,
seed607099:280 ordinary processes. No concurrent builds. Use three existing
10,000-sample clock checks. Per execution:1GiB address space,120 CPU seconds,
180 wall seconds;100,000 ticks per query. Compiler invocations:4GiB,120 CPU
seconds,180 wall seconds. Preserve every failure; repair before further costs.

Compare each generated mode with trace, Direct, scan, indexed and inferred:
ten comparisons per scenario. A runtime gain requires median paired ratio<=0.9
and all five<1; loss requires median>=1.1 and all five>1. Otherwise uncertain.
Both median phase sums must exceed100 times the largest clock p99. Report exact
heap costs separately. The runtime sum includes all recorded source/preparation,
query, observation, consumption and disposal phases. Also report whole-process
wall time, which includes the validation/recording harness and is not bare runtime.

Primary amortization charges generated emission+write+buffer disposal+full
user-program compilation+artifact disposal against an already-installed generic
runtime (zero per-program Rust compilation). Generic wrapper compilation is a
separate packaged-artifact contrast and incremental build control; do not invent
a requirement that interpreted user programs need Rust compilation. Evaluate all
25 combinations of five compiler and five runtime samples; use the same gain/loss
rule over those combinations. Report both phase-sum and process-envelope totals.
Neither implicitly accounts for an unspecified future frontend or runtime system.

If no installed-runtime amortization gain is established at8192 but a generated
mode has medians at least10% below Direct, scan and inferred runtime there, extend
one source to32768 queries. Choose the source/mode with largest minimum median
absolute runtime saving across those three controls; ties use source order then
mode order above. Run all seven modes, two allocation and one ordinary checks,
then five randomized timing blocks. Preserve this conditional selection. Otherwise
record why the extension condition did not hold. No extrapolated crossover claim.

After runtime runs, charge unlinking each experiment-owned emitted file and binary;
retain source copies, hashes, raw results and shared libraries. Losslessly pack
receipts with original/compressed hashes. Audit frozen dependencies, commands,
counts, accounting and artifact disposal. Reassess uncertainty, retention and the
strongest ready portfolio alternative after the resulting comparison.

For the conditional extension decision, pending artifact unlink costs are omitted
as a lower bound. Extend only if even that lower bound has no qualifying installed
runtime gain. Final verdicts include actual disposal. If disposal changes a
qualification, investigate that change explicitly. Compiler and runtime samples
are not discarded or reclassified by the extension decision.
