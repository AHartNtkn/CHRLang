# E08 v1 — persistent independent predicate regions

This first factor experiment asks whether independently solving certified regions and combining their answers removes repeated work across a product of explicit alternatives. It does not infer independence from current variable disjointness alone and does not implement temporary separation followed by reunion.

## Conservative certificate

Construct predicate/arity components from every rule's heads and every constraint reachable syntactically in its body, including both OR arms. Connect all such predicates for a rule. This makes each component closed under rule interaction and future posting. Then merge components whose initial query constraints share any logical variable, including nested term variables. Rule variables are local to applications; fresh body variables stay in the closed predicate component. Pure guards and finite equations have no hidden external effects.

This certificate is conservative: two independent invocations of the same predicate stay together, and an unexecuted linking rule can join components. Record those lost opportunities. A newly linked multiheaded rule must invalidate separation even if its head variables are currently disjoint. Persistent read-only shared facts, finer ownership analysis and conditional reunion remain open.

## Execution and observation

Use the existing E01 persistent scalar engine inside each factor, preserving its independent implementation. Interleave bounded source advances across factors and service product enumeration separately. A newly available regional answer creates only combinations whose latest-arriving member is that answer; each finite tuple must eventually receive service. Keep full residual constraints and rename regional existential variables apart during composition. Reconstruct selected outputs in original query order, including repeated aliases and output variables absent from constraints.

Regional exact deduplication is inherited from E01 and must be stated as an optimization: equal full regional answers are interchangeable under this permanent-independence certificate. For fully exhausted finite factors, record each factor's raw completion count and their product separately from enumerated deduplicated tuples. Do not report that product as physically executed branches, or infer complete raw multiplicity from a finite prefix. Controlled performance cases should avoid regional duplicates when isolating factorization; application cases with duplicates must expose this additional effect.

An exhausted factor with no answer proves the independent product empty, permitting cancellation of unrelated factors. A factor that has merely not answered does not. Infinite producers and bounded prefixes require separate progress checks. The certificate gives commuting regional transitions; declaration-order microstep identity with global scalar execution is not assumed.

## Frozen implementation and matrix

The executable scalar control directly forwards the single E01 engine's answers. The identity product in either mode uses no regional answer cache, renaming pass or second deduplication. This avoids imposing factor overhead on the scalar baseline or on a certificate that finds only one region. Real multi-factor execution records regional and global observation costs separately. Empty-factor cancellation stops service but retains the other engine objects until the experiment ends; memory reclamation is not claimed.

Run the 62 fully exhausted E00 cases, excluding its two unbounded/prefix cases from this complete-result cost matrix. Add 40 product cases with k={1,2,4,8}, W={0,1,8,64,256}, noise={0,16}, and one mixed arithmetic/type-inference case: 103 cases in Scalar and Factored modes, 206 runs plus full replay. The separate tests exercise finite prefixes and empty-factor cancellation.

Each product component has its own pick_i(X_i) and carry_i(X_i,s^W(z)) predicates. All pick rules precede all carry rules in the source control. Inputs share no logical variables between components; unrelated ground noise uses one additional predicate. Expected answers enumerate all 2^k output tuples and their full carry/noise residuals. Scalar source applications are 2^k−1 + 2^k*k*W. Factored source applications are k*(1+2*W). Noise contributes no rule applications. Expected inferred factors are k plus one if noise is present. Both return 2^k distinct full answers; the regional raw-completion sum and complete raw-product count are separate fields.

The mixed case combines the existing addition-forward query with SK identity type inference, freshening the second query's variables and retaining the polymorphic type variable relationship. Its expected output is unary five and fun(A,A), with no residual constraints. It should infer two regions. This is an application composition, not a synthesis throughput claim.

Use a fresh release process per case/mode with a 60-second bound. The driver permits eight times each source case budget to account for product service: 40 million outer steps for product grids, 800,000 for the mixed case, and eight times E00's registered bounds otherwise. A spent bound is not completion. Record certificate predicates/edges/term visits; source steps/applications, equality, matching and persistent-map work; product jobs/tuples, renaming, cache/job maxima; regional and global observer work; and baseline/peak/final allocation payload. Full answers and caches remain charged. Raw-count unavailability is reported explicitly, never as zero. Elapsed time is diagnostic.

Seven behavior tests cover the finite registry in both modes, exact product observations/application counts, shared-variable and linked-rule barriers, residual/free-output freshness, an empty factor beside a loop, finite product coverage with an infinite producer, and regional dedup with complete raw multiplicity. The loop cancellation test changes the scheduling of provably commuting components: global declaration-order scalar execution remains unfinished at its bound while the factored execution finds the independent refutation. Do not generalize that result to arbitrary source reordering.
