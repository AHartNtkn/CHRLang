# S10 first complete-path lifecycle pilot

## Decision and hypotheses

Compare the actual costs of three qualified execution organizations on the same resource/equality/search sources. Existing component gains cannot predict whether conditional claims, contextual equality storage or conventional discovery dominate once preparation and delivery count.

H1: conditional execution may avoid repeated work on shared alternatives, but condition/claim/completion obligations may lose on zero or single deterministic work. H2: contextual equality storage may benefit shared aliases while retaining branch and matching costs; compare its ordinary and persistent shared-deduction configurations. H3: source-certified fusion may save execution yet increase full lifecycle cost; compare each organization with and without it. None is a presumed winner.

The strongest ready alternative is precise isolated fusion timing. This whole-path pilot can instead change the selection among distinct search/equality organizations. Its bounded resource-family scope is an initial cost screen, not the held-out architectural comparison. Mixed history/guards, early failure, sustained streams and broader sources remain required after it.

## Frozen comparison

Twelve modes: original/fused × compiled Global Scan, compiled Global Indexed, inferred-specialized Global Scan, ordinary contextual, persistent contextual with shared deductions, and direct conditional. Five source families: plain, choices, duplicates, shared payload, spare resources. Counts 0/1/3, prepared reuse 1/4: 360 cells. Reuse changes owner keys, payload variables and query marker. All queries in this pilot satisfy the source certificate; ineligible-query semantics were checked separately and their switching costs remain unmeasured here.

Allocation: two independent release processes per cell (720), order seed 7810. Require exact per-phase memory readings between repetitions and every ownership restoration assertion before timing. Timing: five ordinary-allocator counter-free processes per cell (1800), independently shuffled seed 7811. One correctness-checked warm batch precedes measurement in each process. Each query's complete raw answers are checked against the independent scalar outside measured intervals. Allocation is requested heap traffic/live bytes, not RSS. Allocation timings are not primary timing data.

Source and binary hashes are recorded before the matrix. Each subprocess gets 1 GiB address-space limit, 60-second CPU limit and 75-second wall timeout. Entire finite query has 200000 service calls. Every cutoff/error is retained and blocks comparative interpretation; never treat it as exhaustion. Do not silently reduce cells or restart live processes. The single debug ordinary-conditional/plain/1/1 runner check preceding registration established API and ownership viability only; it supplies no comparison.

## Measured ownership and observation

Separate inference, each query's input creation and certification, first-query reusable preparation, setup, first answer delivery (or exhaustion for no answers), remaining delivery, engine disposal, answer disposal and input disposal. Then measure cancellation input/certification/setup, one service operation and disposal, followed by prepared and inference disposal. Cancellation proves release at that API boundary, not equal semantic progress.

Observation is part of service in contextual and conditional public APIs. Compiled completions are exported immediately to the same owned-answer endpoint. The two delivery phases include execution AND observation; do not label them isolated execution. All answers are retained until query completion, giving the same finite batch consumer policy. Source generation before inference, oracle work, process startup and native compilation are excluded. Preparation means runtime preparation, not native compilation. No complete architectural lifecycle superiority claim follows without those remaining costs.

## Interpretation

Requested allocation differences are deterministic observations only after exact replay and owner checks. Show traffic and peak retention separately, including preparation and disposal. Timing is exploratory: report medians and ranges for matched cells, no practical-win classifications or pooled workload score from five samples. Investigate large contrary findings, ownership defects and cutoffs before refining precision. Report clock overhead honestly; do not subtract estimated overhead. The prior clock probe informs caution but is not a calibration for a different clock platform.

A favorable result advances a candidate to broader mixed sources and sustained lifetime. A loss prompts attribution to necessary obligations versus avoidable implementation costs. Overlap leaves the timing question open. At this package boundary, reconsider the strongest ready unresolved alternative and retain every consequential obligation.
