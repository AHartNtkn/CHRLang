# S04 complete source restoration: prospective gate

Implement three source search organizations over the same mutable execution primitives: copy state at choice, reversible changes with undo/redo between queued interpretations, and replay from the initial query using recorded source choices and progress positions. Keep rule/tuple selection deterministic and use FIFO service across interpretations. No organization may replace unfinished work with failure or starve a finite sibling merely because it uses a trail.

State includes bindings, immutable constructor-valued terms, identified live source occurrences, propagation history, pending body effects, and fresh variable/occurrence counters. Share immutable terms, occurrences and pending syntax within copied states where possible; do not create an artificially deep-copying control. Reversible edits must cover every mutable component. Queued interpretations retain checkpoints; switching restores through a common ancestor and redoes the target path. Release unreachable branch paths, and avoid retaining linear history when only one interpretation remains. Replay recomputes deterministic prefixes rather than treating recorded answers as reusable results.

Use full syntax with consuming/kept heads, nonbinding constructor patterns and repeated variables, stable equality guards, conjunction, explicit choice and finite-tree failure. Reject empty-head rules and identity exhaustion explicitly. One source step may contain size-dependent matching/equality work; source-step fairness is not a fixed wall-clock latency guarantee.

Before comparative timing, check complete raw observations against the independent owned-syntax scalar evaluator and selected hand-derived outcomes. Include rollback after partial failed unification; restored consumption; propagation history across siblings; fresh locals and occurrence identities; nested choices with pending conjunction tails; repeated aliases and constructor cycles; duplicate alternatives; cancellation/preparation reuse; and a finite sibling beside ongoing recursive work. Exercise common-ancestor switching and different source rule orders on order-independent fixtures. Deliberately omit at least binding, resource, history and pending restoration in diagnostic mutations and require semantic failures.

Bound finite cases at 100,000 scheduler advances and each test process at 60 seconds. Replay prefixes and undo/redo lengths are separately finite but may grow; do not call a scheduler advance constant-cost. A cutoff fails the finite gate. No performance ranking follows. The later lifecycle comparison must include the existing compiled/persistent control, quantify this representation's costs, and distinguish root replay from checkpointed replay and richer trail organizations.
