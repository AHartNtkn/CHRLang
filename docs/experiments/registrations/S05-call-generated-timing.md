# Paired runtime timing of qualified generated callers

Registered before comparative runs. Use the frozen counter-free ordinary binaries
from matched compiled costs and the repaired generated source-check campaign.
Their source/ownership gates already pass. Rerun both ownership audits before
sampling; preserve every binary and receipt. No builds during timing.

Seven modes: trace, Direct, compiled scan, indexed, inferred, generated indexed,
and generated plus inferred. The existing 144 scenarios per mode use four
families, depths 4/32/128, one query / four repeated / four distinct queries,
retained output 0/all and full / first-answer cancellation. Run ten randomized
complete blocks of 1,008 cells, seed 607097: 10,080 processes. Each has 1 GiB
address space, 30 CPU seconds and 45 wall seconds. Any failure stops for repair;
no failed or slow samples are excluded. Three existing 10,000-sample clock checks
precede runs.

Primary cost sums every recorded lifecycle phase: source and preparation, query
input/setup, service/observation, consumption, and all disposals. Check complete
answers outside intervals and require consistent output counts across modes.
There are eight comparisons per scenario: trace against each of six controls,
generated against generic indexed, and generated-inferred against generic
inferred. Qualify gain at median ratio <=0.9 and all ten ratios <1; loss at median
>=1.1 and all ten >1. Otherwise report uncertain. Both median costs must exceed
100 times the largest clock-check p99. Carry exact requested/peak ownership from
the qualified campaigns alongside time; do not infer RSS or workload weights.

Inspect overlap with the preceding eight all-control trace gains and attribute
consequential results to phases. These diagnostics do not introduce extra timing
verdicts. Runtime sums exclude process startup and user-program compilation; this
experiment selects the regimes for the separate replicated compiler/artifact and
long-query-amortization comparison. Do not infer compiler lifecycle superiority
from runtime-only gains. Reassess retention, broader observers and sparse
projection once the generated comparison changes their relative decision value.
