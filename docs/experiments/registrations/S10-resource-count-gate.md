# Source-derived private traversal resource counting

Infer a consuming unary traversal from source structure: one rule keeps a nullary permit, consumes run(successor(N), R) and a nullary fuel, and posts run(N, R); one terminal rule handles run(zero, R). Names and variable numbers are arbitrary. Infer a single-entry rule whose successful body paths invoke that traversal exactly once with a successor prefix over N, while all other body uses of N are forbidden. Failed body paths may invoke it zero times. Reject extra readers/writers of private run/fuel, permit consumption, entry production and competing entry heads.

Query certification requires exactly one structurally matching entry, a ground successor/zero depth d, at least d fuel occurrences, a permit, no initial private run, and no other initially active head predicates. Return a transformed query with d fuel occurrences consumed and entry depth replaced by zero; source rules are unchanged. Inference/transformation uses no evaluator or expected-answer fixture. Any branch-specific successor prefix remains for ordinary execution. Queries outside eligibility retain ordinary execution.

The soundness obligation is that these unobserved nonbinding fuel steps commute across admitted entry choices/equalities, preserve residual multiplicity and fresh variables, and cannot deprive another consumer. This is an optimization certificate, not a language restriction or arbitrary scheduling-trace equivalence claim.

Test predicate/constructor/variable renaming; common/independent/early sources; choices 0/1/3; depth 0/1/4/16; changed queries. Compare original/transformed complete answers to independent constructed observations and the scalar. Challenge insufficient fuel, unknown/malformed depth, missing permits, competing readers/writers, absent/repeated entry, observable depth uses and mismatched entry heads.
