# Mixed nonground posts and consuming continuations: source/work gate

T078 investigates whether demand's passive-post benefit survives substantial common or branch-dependent consuming work. Existing explicit execution, conditional sharing and source-derived elimination remain competing paths. This gate precedes lifecycle registration; it produces no timing ranking.

## Source and hypotheses

A start call makes k named binary choices, emits a token whose argument is its not-yet-bound output, and consumes that token before a depth-d traversal. Each traversal step consumes a fuel occurrence and keeps a permit. Completion produces a fresh unknown shared between the exported result and a residual pair. Independent-work sources extend the traversal once per b choice; early-failure sources reject the first b arm. Original/reversed query arrival and two distinct query identities are independent axes. A history-bearing variant propagates one mark from the permit.

H1: supported demand paths preserve complete answers, resource multiplicity, nonground post dependencies and fresh aliases across this combination. H2: conditional common-work sharing reduces actual step applications relative to explicit complete traces; branch-dependent work and early failure constrain that claim. H3: source-derived resource counting either certifies the complete source and preserves independent answers, or reports a concrete eligibility obstruction. Admission is not inferred from a neighboring fixture.

## Fixed initial scope and controls

Three families (common, independent, early) × choices 0/1/3 × depth 0/4/16 × original/reversed arrival × history absent/present × query identity 0/1: 216 complete source configurations. Reuse each preparation across the two query identities and arrival variants. Check full independently constructed answers against the independent scalar, generic Global Scan/Indexed, inferred Global Scan/Indexed, inferred Active Scan/Indexed and direct conditional execution. Test demand StaticBirth, plus miss reuse, plus miss/template reuse wherever preparation accepts. Record exact admission failures; the history-bearing source remains in scope even if demand rejects it.

Keep the existing post-choice fixture as an additional admission control. Probe the existing resource-count compiler against each complete mixed ruleset; if it accepts, qualify its query transformation with the same full observations before treating it as a stronger control. No source-name dispatch or oracle-generated execution.

## Validation, bounds and interpretation

Per complete execution: 2,000,000 service operations. Run the test process under a 180-second wall bound initially; preserve any cutoff and identify its case before extending a bound. Run counters-off and work-diagnostic builds separately. Conditional application traces and scalar source traces are work evidence only. Independent expected outputs specify all 2^k alternatives (or surviving early alternatives), unused fuel, permit, optional history mark and one locally shared fresh variable. Compare raw multiplicity, not just unique values.

Cancellation probes stop after 1 and 4 service operations, then reuse the same prepared source; retain complete answers until preparations are dropped. The initial gate does not establish interruption within one service operation, sustained memory, RSS, compile cost or total efficiency. Diagnose consequential mismatches without suppressing sources or weakening expected answers. At the first gate result or obstruction, reconsider lifecycle work versus broader demand capability, integration, recognition and sustained ownership under the portfolio review.

## Fixture and control repair before cost measurement

Initial source runs exposed three test-interface problems and an overly narrow counting entry: Active execution must use the nonsealed preparation; inert query predicates needed correct demand classification; and static permit propagation needed an explicit compiler pass for the demand path. Fix those responsibilities rather than ending the experiment at admission failures. Preserve the initial source snapshot and all attempts.

The revised mixed source places nonground token production and consumption in the traversal terminal. Common/early families make closed value choices before their shared continuation; the independent family places branch-dependent successor prefixes inside the source alternatives. All original matrix axes and complete observations remain. Static inert propagation is initialized from the actual source and query occurrence counts. Closed value-choice prefixes become fresh-output producer rules for demand preparation, with fresh predicate names. The counting control must now infer and execute on every matrix cell; an admission rejection is a failing gate, not a completed result. Primary cost measurement will charge these compilation/preparation and query transformation duties.

The six explicit source controls are generic Global/Active Scan/Indexed and inferred Global Scan/Indexed. The sealed inferred mode does not implement Active execution; generated Active controls will use their actual generated preparation in the lifecycle runner. No timing comparison has started.
