H1: retained failed regions can repay recognition and ownership when compatible queries avoid sufficient common work. H2: eager complement splitting and covered-state checks can have different depth/reuse regimes. H3: absent reusable failures can make either learning policy a net cost. This concerns the qualified finite fragment with full caller results, not general conflict learning or architecture-wide superiority.

Freeze the current primary and diagnostic binaries from s06-learning-prefix-entry and verify its source receipt before any run. Use all 81 configurations from policies recompute/eager/covered, acceptance masks 0/484/511, depths 0/16/64 and follow-ups 1/4/16. All use weight one, capacity four and no cancellation. Masks supply all-failure, reusable failure plus success, and no-failure cases. Check full independent answers using the executable's scalar and compiled oracles and analytical multiplicity, diagnostic repeatability and heap restoration. Any mismatch or cutoff stops for diagnosis. Then run one excluded primary warmup per configuration on each CPU0/1 (162), and five primary repetitions per configuration per CPU (810). Randomize configuration order separately for each warmup and measured block using seed20260918. Freeze this order before execution. This is a descriptive pilot, not inferential confirmation.

Full answer validation occurs outside those phases. Also report service-only sums to diagnose boundaries. Process wall includes independent validation and is an operational bound, not an engine timing endpoint. Outer preallocated consumer/phase storage is excluded. Ordinary allocation and disabled diagnostics are mandatory for timing. Compilation, artifact lifetime, external publication and sustained consumer regimes remain outside this claim.
