# E14 v1 — independent exact alpha-equivalence service

Question: can experimental engines compare full residual answers without importing reference canonicalization, and what work does direct bijective matching require on distinguishable and symmetric residual graphs?

The service fixes output-variable mappings first, then searches for a bijection between residual occurrences and variables. Predicate names/arity reject candidates; successful mappings are injective and shared with outputs. Multiset multiplicity is preserved. This algorithm checks pairs; it does not promise a canonical label or subfactorial worst-case complexity. Experimental answer sets retain all distinct answers and compare them exactly.

Correctness cases include output aliases, constructor positions, occurrence permutations, failed partial-match rollback, distinct multiplicities, output names, and connected versus disconnected regular graphs. Exhaustively compare all 4,096 pairs of directed loop-free graphs on three explicit vertices against an independent six-permutation adjacency oracle. The finite graph test does not prove arbitrary-term correctness; the bijection construction supplies its direct argument.

Cost probe families are labelled unary occurrences, indistinguishable unary occurrences and a directed cycle versus two disconnected cycles. Sizes for labelled/symmetric pairs: 0,2,4,6,8. Negative cycle pairs: 4,6,8. Renamings and reverse occurrence order are deterministic. The labelled and symmetric pairs are equivalent; connected/disconnected cycles are not. Each pair is also emitted as two explicit alternatives through the reference, checking that its final recognized-answer count is one or two accordingly and its raw completed count is two.

Record actual term-pair visits, occurrence scans, structurally eligible candidates and backtracks from the independent service. Record reference total steps and raw/final answers separately. Reference elapsed time includes construction, execution and canonicalization; it is diagnostic, not an isolated normalizer timing or a claim that pair matching and canonical labeling are identical operations. Freeze code and this registration before the cost batch; run once and replay all non-time fields. Allow 60 seconds per process; no larger size is required for this initial probe. No hardware timing comparison is claimed.

A sound independent observer unlocks E01 comparisons even without a speed advantage. Expensive symmetric failures would motivate structural partition refinement or exact indexing, not approximate deduplication. This batch does not close output latency, retained-key memory, comparison across large streams, logical projection, or global quiescence questions.
