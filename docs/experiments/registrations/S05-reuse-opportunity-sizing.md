## Interpretation

This is sizing, not confirmation: no practical gain/loss classification or speed certainty from one sample. Meter elapsed times are not speed evidence. Retain no-choice, distinct-future, large-payload and low-work controls. Source/preparation growth with alternatives must count. No workload weights or universal winner follow from component measurements.

Investigate whether each source actually produces the intended reuse and whether key construction or retained state remains consequential. Use the strongest applicable compiled, graph-template and exact-source control when choosing confirmation. A useful table mechanism can still lose to elimination. Reconsider sustained S08 and remaining S02 at the next package boundary rather than automatically extending the same workload. Call-level reuse, broader relevance and eviction remain required.
