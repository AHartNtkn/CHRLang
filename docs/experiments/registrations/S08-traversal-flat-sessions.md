# Precision for the flat single-alternative comparison

Use all 20 flat one-alternative configurations: pure/resource, immediate/all consumers, direct and dependency/template cache off/on. Every complete lifecycle still builds preparation, runs two marked queries, validates complete answers and exhausts/disposes all engine and consumer ownership. Run 50 such independently owned lifecycles per process, nine ordinary blocks and two metered blocks, shuffled with seed 7402: 220 processes, 11,000 complete lifecycles. No preparation or graph survives between them; source/oracle and reporting work remain outside the existing phase intervals. RSS polling is disabled in this precision comparison.

Require exact normalized allocation phases across all 50 sessions and the two metered repetitions, including final release.

Report unresolved comparisons explicitly; do not turn a tiny magnitude into an architecture rule. These trials test whether a single-alternative representation tradeoff is real.
