# Resource-candidate copy attribution

Attribute the ownership loss before choosing a matching repair. The previous nonground-post comparison finds 12,259,743 requested bytes for the size32 original-order miss-reuse case, versus 998,792 for specialized explicit execution. Of demand's traffic, 11,671,384 bytes occur during execution/observation. That leaves a consequential but unproven possibility of avoiding matching allocations. Direct integration is the strongest ready distinct alternative; this is one bounded attribution package, not a commitment to further demand tuning.

Hypothesis: copying candidate arguments, match environments and selected occurrence lists accounts for a substantial part of this execution traffic. Instrument those three operations separately, with nonnested allocation-free callbacks and cumulative meter checkpoints. Selection includes both copying and appending. This measures requested allocation inside those operations, not all matching costs, deallocation lifetime, RSS or speed. Counts apply after preliminary resource filtering, not every visited resource.

Use the existing dependency_ownership runner and the frozen s03-post-ownership controls. Select all six source families, sizes8/32, both arrival orders, birth/birth-miss/birth-miss-template, retained-all outputs and full/alternating-cancel execution:144 configurations. Run two isolated profiling processes per configuration,288 total. Preparation is reused for four alternating a/b queries. Preserve independent complete-answer checks and retained answers after producer disposal. No new baseline or primary timing matrix is required.

Build release with no default features and candidate-profile (implies allocation meter), with engine/kernel/work counters off. First-observation clocks are off. Freeze sources, binary, exact cells and parent evidence hashes before the first matrix process. Preserve raw commands, stdout, stderr, failures and timeouts. Run meter self-check first. Bound each workload to CPU0,60seconds wall/CPU,1GiB address space and the existing2million service steps; bound the campaign to30minutes and build to300seconds. No warmups are needed for allocation attribution; no timing values are interpreted. Use deterministic cell order and two repeats because the outcome is exact counts, not a timing estimate.

Qualification requires identical phase allocations, live-heap changes, peaks and endpoints to the frozen parent after normalizing process baseline and omitting time. The two attribution repeats must also agree exactly. Require paired argument/environment scopes, selection scopes no greater than candidate scopes, and attributed requested bytes no greater than execution/observation traffic. Any failure invalidates attribution until causally diagnosed; retain the failed receipt. Exact parent agreement tests instrumentation's effect on measured ownership directly.

Interpret each source separately, without weights. Subtract attributed bytes from total demand traffic as an optimistic allocation bound; do not call that an achievable saving. If even eliminating all three costs cannot reach the strongest explicit control, these copies alone cannot reverse that allocation comparison. If the bound can reverse a consequential loss, qualify a sound copy-avoidance variant before inferring its value. Charge its new invariants and preserve partial head bindings, late aliases, competing claims and cancellation. A copy repair does not answer resource scanning, primary timing, sustained ownership or broader demand eligibility. Reconsider direct integration and intermediate joins at the result boundary.
