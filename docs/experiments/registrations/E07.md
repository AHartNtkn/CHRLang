# E07 v1 — certified ancestor work before explicit splitting

This first delayed-split probe isolates ancestor work that can commute before an explicit choice. It uses the E01 persistent storage, term and equality implementations as shared experimental services; the reference remains independent. Early and delayed policies execute the same state implementation, differing only at an explicit OR. It is not a complete implementation of nested Andorra child boxes.

## Conservative lifting boundary

A statically eligible rule has one removed head, no kept heads or guards, a linear head pattern, and a body containing exactly one constraint of the same predicate/arity, using only head variables. No other rule has that predicate/arity in any head. At the pending OR, both arms and the pending suffix must contain only equations, conjunction, nested explicit OR, true or fail. Constraint-posting arms are a barrier in this version. The engine may lift an enabled eligible application and its body introduction, preserving the postponed choice. Each choice counts its lifted applications and splits when its finite quota is reached.

The reason this is a commuting boundary is specific. The eligible reduction changes only its own isolated occurrence, writes no logical variable and posts no other predicate. A previously successful linear match remains a match under any successful additional finite substitution, and instantiating its body then applying that substitution gives the same terms as matching after substitution. If an arm's equations fail, either order fails. Other rules cannot observe or consume the isolated occurrence through their heads. Pure equation/failure arms and suffixes introduce no new resource interaction. Thus a finite lifted reduction commutes with the postponed arm work up to fresh occurrence identity. This is an observational commuting transformation, not a claim that declaration-order microsteps remain identical.

The restrictions are experimental certificates, not adopted language restrictions. General CHR continues to execute normally when lifting is unavailable. A common ground occurrence can be consumed conditionally without itself being bound: the dedicated p/q test must refuse lifting when the consuming rule shares the p predicate. Propagation/multihead examples in E00 remain full-observation controls.

## Fairness and scope

A quota limits lifted applications per pending choice; one application and its introduction require separate state steps. Each state receives FIFO service. It does not bound the wall-clock duration of matching, certificate traversal or unification. An unbounded-preference policy is an adverse experimental control, never a default. A looping common producer with two failing arms must refute under finite quotas; the unbounded control may remain unfinished at the registered budget. That prefix is not evidence that the source program has no result or that divergence is failure.

The first implementation does not execute child producers while a choice remains undistributed, perform promotion after child failure, or implement an adaptive quota. Those remain live E07 questions. This boundary permits measuring opaque common work and speculative work discarded after failure while testing resource restrictions concretely; it cannot stand in for the full E07 program.

## Frozen matrix

Run 64 E00 cases; the 75 carry cases k={0,1,2,4,8}, W={0,1,8,64,256}, noise={0,16,128}; 15 doomed cases W={0,1,8,64,256}, noise={0,16,128}; and one infinite-common-producer refutation case. Policies are quotas 0,1,8,64,256 and Unlimited. Total: 155 cases × six policies = 930 runs, plus full replay. Each fresh release process has a 60-second bound. Grids receive one million state steps, E00 its own bounds, and the refutation case 2,000 steps.

For natural carry, let B=2^k and q be the quota (use q=W for Unlimited in this finite formula). Expected physical applications are B−1 + Σ[j=0..k−1] 2^j*min(q,max(W−j*q,0)) + B*max(W−k*q,0). The sum is the expected lifted applications. Quota zero therefore performs B−1+B*W; a quota covering W performs B−1+W when k>0. Choice preparation is still executed per source branch; it is not cached as in E04.

Doomed cases replace both pick arms with contradictory equations: X=a then X=b, or the reverse. Both fail, so expected answers/raw successes are zero. Early execution performs only the pick application. Delayed execution performs 1+min(q,W) applications, with the lifted work subsequently discarded. These controls oppose the opaque-success workload without changing observation requirements.

The refutation case has an isolated loop(X) <=> loop(X) plus a choice whose arms both fail. Finite quotas must exhaust after 6+2*q steps with two failed branches and q lifted applications. Unlimited is intentionally registered as unfinished after 2,000 steps, with no failures yet serviced. This is a bounded adverse scheduling observation with a known finite source refutation, not source failure/divergence equivalence. The existing S01 case separately checks a finite answer beside an infinite alternative; its constraint-posting arm is a lifting barrier here.
