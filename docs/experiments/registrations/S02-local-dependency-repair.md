## Hypothesis and responsibilities

A constructor test on a descriptor-free value cannot become ready solely because that value aliases another descriptor-free value. A repeated-variable test can become ready when two unknown inputs become identical. The existing single watcher set wakes both on every merge, producing `2n + n(n+1)/2 - 1` inspections in the broad constructor witness.

Separate descriptor subscriptions from unresolved-equality subscriptions. Subscribe only to information still needed for the inspected match. Constructor signatures and established equality are monotone under successful unification; a conflicting merge fails the whole branch before token service. Captured values use stable handles that already follow endpoint repair. Preserve source request order and consume only after pending equations settle.

Equality subscriptions may still conservatively wake on irrelevant endpoint merges. This package must expose that limit rather than claim fully minimal dependency repair. Handle relocation, watcher migration, consistency traversal and source matching remain real responsibilities even if request-inspection counts fall.
