When a current unkeyed pool can be constrained by a later keyed head, inspect that keyed pool on copied frames, obtain candidate current occurrences through the resulting keys, union IDs in original ascending order, then let ordinary matching and guards select the actual tuple. This is an overapproximation of viable current occurrences, not an early commit or a rule reorder.

Compile-time feature selective-probe selects the experiment; default retains the existing control. Do not claim a generated/native plan benefit. Counters separate probe starts, inspected later occurrences and produced candidate IDs from existing candidate, structural, frame-copy, index and pool work.
