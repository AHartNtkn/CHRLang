# Support identity and completed-result mechanism gate

Compare existing Boolean jobs, direct cheap-root results, bounded arena-local completed-result reuse, and their combination. This gate establishes correctness and source work; it makes no allocation or timing claim. Cache capacity256 and insertion-order eviction are experimental controls, not tuned policies or architecture decisions. Cache only substantive completed roots; cheap results are handled by the independent identity feature. Queries own separate arenas.

Independent Boolean tests cover all16 two-variable truth functions under Not/And/Or/Difference at capacities0/1/4, repeated operations, eviction/recomputation, new nodes, interrupted and interleaved jobs, independent arenas and foreign-job rejection. Full source tests run each feature alone and combined with counters disabled, serial accounting, head dispatch and precise equality invalidation. Also verify direct cheap jobs require no continuation/memo allocation structurally.

For a bounded source work check, build all four policies in release with no defaults, experiment,support-trace,serial-body-accounting,head-dispatch,equality-invalidation plus the applicable optimization features. Use inferred alias streams at depth0/64, work4,payload8,resource=true,successful terminal:8 runs. Freeze source, registration, driver and each binary before running. Validate complete answers independently. Record service ticks and trace roots/frames, including zero-frame direct or cached results. Preserve1GiB/120CPU/150wall-second and2million query-service bounds. No clock or allocation inference from these trace builds.

Require ordinary-policy service counts to agree with prior source traces. Other policies may change tick counts but must preserve complete source results, aliases, multiplicity and finite-service guarantees. Even a large reduction requires subsequent complete lifecycle allocation/timing, cold/sparse/changed-context sources and retention/cancellation tests against strong Scan/resumable controls. Reconsider breadth and the non-overlap/effect alternative at this gate before extending the cache policy.
