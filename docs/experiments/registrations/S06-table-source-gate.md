# S06 finite table-source compilation gate

Compile a sealed ruleset with one selected request predicate and distinct finite table predicates. Every rule has one removed head, no kept heads and no guards. Heads contain distinct variables. The request body is a conjunction of table calls (with repeated variables, constructor terms, givens and fresh locals allowed). Every other rule is a table: nested explicit OR of rows, where a row is a conjunction assigning each head variable exactly once to a ground finite term. True is one zero-arity row; Fail contributes no row. No competing definitions, recursive calls, source observers or other effectful rules are admitted. Inspect the entire supplied ruleset; return an eligibility error on a near miss.

The target relation is a bag join of row occurrences. Duplicate rows retain distinct derivations. Each request expands its local variables freshly, each actual table-call occurrence selects one row, and all column equalities must hold jointly. Query aliases, repeated arguments, structured unknown arguments, ground givens and passive residuals preserve full joint observations. Queries may contain several requests or direct table calls. Constraints whose signatures have no source rule remain passive residuals, as in source execution. This is a finite, terminating fragment; it does not establish progress or contextual contraction for arbitrary CHR.

Independent oracle: owned-syntax scalar execution, without candidate imports. Additional mathematical tests enumerate row-index products before filtering equality and compare exact raw answers, including non-output failure and residuals. Vary sparse/dense and duplicate tables, shared/disconnected variables, repeated arguments, multiple requests, constructor rows, ground contradictions and unknown residual aliases. Reject near misses: observing/competing rules, kept heads, guards, structured/repeated head patterns, missing/non-ground row assignments, recursion and body effects. Rejection establishes this certificate's boundary, not semantic impossibility of broader compilation.

Implement a direct path selecting rows through relation column indexes and ground-term substitution, without CHR occurrences, propagation history or interpreter traces. Preparation owns table extraction and indexes; query setup owns request expansion and unknown identity. Enumeration must remain lazy across answer products and preserve duplicates. Gate bounded queries at 100,000 advances, each process at 60 seconds. Any cutoff fails the finite gate. Record tests, replay, contrary cases and source hashes before registering comparative lifecycle runs. No timing ranking follows from this gate.
