# S05 complete-caller ownership gate

This is an allocation-ownership diagnostic, not a timing comparison. Validate the assembled private-phase/caller path before registering native costs.

Use Direct and Memo call tables; recursive depths 0 and 8; cancellation before expansion, after expansion, after first answer, and ordinary exhaustion. Each of the 16 configurations runs two identical-call queries over one prepared caller. The private result has two raw alternatives and contains a fresh variable twice. An outside supplier binds a shared input after replay. Compare retained complete answers to independent source evaluation outside measurement.

Allocate the fixed answer buffer and immutable source inputs outside the owner baseline. Read requested live heap bytes after prepared construction, after each caller is dropped, after its retained answers are released, and after prepared disposal. Cancellation must not publish extra answers. The prepared cache may retain private interface results between queries; after prepared disposal, all task-owned live bytes must return exactly to the starting baseline. Returned answer contents must remain valid after caller disposal.

Run a counter-free allocation-meter release binary twice as fresh processes. Require exact replay of all diagnostic rows and restoration baselines. Bound each process at 60 seconds and 1 GiB address space. Record source/binary hashes, compiler version, commands and complete receipts. Validate ordinary semantic tests separately; meter elapsed times supply no speed evidence. Compilation and phase timing are outside this gate.

A failed baseline or changed retained answer blocks comparative costs and requires ownership diagnosis. A successful gate permits prospective lifecycle timing design; it does not establish efficient retention or a complete architecture. The implementation's private expansion is a bounded synchronous step, so cancellation inside that step is represented by its explicit service-limit error, separately tested. External asynchronous interruption remains outside this gate.
