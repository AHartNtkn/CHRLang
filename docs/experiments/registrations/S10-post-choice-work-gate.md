# S10 substantial common work after choice

Qualify whether conditional execution actually avoids repeated source work. The common source performs k independent source choices, then a consuming depth-d traversal using fuel and a kept permit; its final fresh unknown is shared by output and residual. The common continuation is syntactically outside the choices. An independent control duplicates continuation into the choice tree and makes traversal depth depend on the number of right arms. An early-failure control rejects the first right arm before common traversal. These are distinct sources, with independently constructed complete outcomes, not matched-speed claims across different tasks.

Vary choices k=0/1/3 independently of depth d=0/4/16 and two changed queries: 54 configurations. Compare compiled Scan, Indexed, inferred-specialized Scan, contextual eager/demand/shared-persistent and direct conditional. Full raw observations must match independent expectations and the separate scalar evaluator, exhausting within 500000 service calls. Fuel residuals differ in the independent control and must remain observable. Prepared rules are reused between changed queries.

Separately enable conditional application tracing. Count physical step-rule applications, and compare with the independently derived explicit-path step count: common 2^k*d; early k>0 gives 2^(k−1)*d; independent gives 2^k*d+k*2^(k−1). At k=0 the latter is d. Check complete answers in the traced run. A count reduction establishes the mechanism, not total efficiency. Check feature-off semantics separately; do not use instrumented elapsed times as primary performance evidence.

If conditional work does not decrease, investigate actual continuation/source representation before calling this a favorable sharing witness. No comparative lifecycle timing is registered here. An allocation/cost registration follows only after this mechanism gate passes, with preparation, disposal, output multiplicity and a strong source-derived control considered. This is not held-out evaluation or architecture closure.
