# Native identity operations before source compilation

T080 requires a native source representation that distinguishes occurrence history from current equality. The current ground-count compiler cannot express those distinctions. Establish native operations over unknowns, atoms, occurrence IDs and ordered histories before integrating rule selection. This is an implementation prerequisite, not a substitute for the 61 complete-source obligations or the serial/local ownership comparison.

Use the frozen interruptible structured native observer from the consuming gate, without rebuilding the substrate. Run independent small equality expectations for four unknowns and two distinct atoms, including reflexivity, chains, repeated binding, conflicting atoms and nonbinding equality. Exercise occurrence replacement/removal, ordered receipt membership and distinct-head eligibility independently. Include choices whose shared unknown receives different branch bindings, duplicate alternatives and failed alternatives. The oracle is a Python equivalence-class model; it must not call the native operations or derive expected answers from their output.

Before implementation, demonstrate an equality test failure against a runnable incomplete operation. After implementation, enumerate all two-binding sequences over variable/atom pairs for a declared small operand set and targeted longer chains. Record exact case definitions and expectations before native runs. Use two repetitions, service quotas 1 and 8, 8192 service calls, three wall seconds per process, and the existing native gate's address/CPU bounds. Preserve failures and cutoffs; do not silently increase limits. Validate complete outputs and exhaustion, service visits, replay, counter-off behavior and cancellation prefixes at calls 0, 1 and 16. Use ordinary native collapse as a finite-case control on representative cases.

No comparative timing, allocation efficiency, arbitrary constructors, general CHR admission, local concurrent effect ownership or full source correspondence is claimed. The next integration must preserve source rule priority, occurrence replacement, fresh body variables and propagation history on the already registered source obligations.
