# Dependency admission and staged observation gate

Package two after the continuing-service breadth review. Resolve two assumptions exposed by the bounded local-claims gate, before native source integration. No timing or architecture winner is sought.

Admission: reuse all six frozen one-shot scenarios, each cancellation target and the independent source-priority atomic oracle. Compare occurrence-conflict components with components additionally connecting every binding writer to every potential binding reader. Edges include consumed/kept conflicts; transitive components select their earliest currently enabled application. Components are computed from complete finite application descriptions before execution, including disabled readers. They are not yet inferred from arbitrary CHR sources. Enumerate both schemes (40 cells) with the existing acquisition/commit protocol. Record all terminal observations, deadlocks and source-priority differences. Require full dependency components to match the priority oracle exactly; occurrence-only components are a hypothesis under test, not a designated correct control. Record simultaneous admission of independent applications. Bound each cell to 200,000 states and the run to 2M states, 60 CPU/wall seconds and 1 GiB.

Publication: independently model one transaction changing four separately stored fields (two consumed identities, a binding and an effect). Install descriptor references one at a time. A single descriptor status changes from pending to committed only after all references exist; cancellation changes pending to aborted. Resolve a referenced field to old/new from that status. Materialize committed values or remove aborted references one at a time. This is an explicit state-machine implementation of the visibility mechanism, not a native machine-code or memory-ordering proof.

Interleave an observer's four separate reads with every writer step. Compare direct field reading with a status-validated scan: record status before reading and publish only if it is unchanged afterward, otherwise discard the scan. The independent permitted snapshots are all-old or all-new; no partial effect is valid. Enumerate cancellation allowed/not allowed, both observers (four cells), including scans during materialization and cancelled partial installation. Preserve shortest mixed-snapshot witnesses. Require validated scans to publish only permitted snapshots and to admit both all-old/all-new observations where commit remains possible. A discarded scan is recorded as a retry obligation, not a successful observation or a progress proof. Observer rescheduling, multiple descriptors, source integration, weak-memory synchronization and descriptor reclamation remain required. Bound each cell to 200,000 states, run to 2M states, 60 CPU/wall seconds and 1 GiB.

Freeze implementation, independent checks, configurations and registration before each run. Preserve cutoffs and failures. A passing gate selects the physical/source integration question next; it does not establish general distributed CHR correctness. Reconsider adaptive costs and the other required directions at that gate or a consequential obstruction, with the full breadth review after four packages.
