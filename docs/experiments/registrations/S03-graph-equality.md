# S03 direct graph equality: prospective semantic gate

The direct graph needs finite-tree equality and nonbinding equality tests before source matching can use unknown terms. This experiment adds contextual redirects for logical unknowns while retaining constructor and choice nodes. It does not choose the final equality architecture or claim a complete CHR executor.

A variable binding is a graph-node reference valid in a sparse choice context. Dereferencing intersects the requesting context with binding regions and preserves unbound complements. Binding an unknown to an acyclic choice-valued term should retain that graph reference without enumerating complete histories. Occurs checking may inspect descendants; it must reject exactly the contexts with a finite-tree cycle. A top-level self alternative, X = choice(X,a), is reflexive on one arm and must not be rejected as X = f(X). Constructor clashes and explicit failure permanently invalidate only their contexts. Failure must affect observation even when the failed equation is disconnected from all observed roots.

Nonbinding equality reports regions where two existing values are already equal. It must never instantiate independent unknowns, create a failed region or change later observations. Shared unknown identity, structural equality and repeated correlated choices are all relevant; physical node equality alone is insufficient.

Before behavior implementation, write tests for contextual bindings and late aliases; immediate and indirect cycles; cycles in only one choice arm; reflexive top-level choice arms; constructor-name and arity clashes; unrelated failure; equal-arm multiplicity; and nonbinding queries before and after binding. Add an independent scalar finite-tree substitution oracle in the tests using owned test terms, exhaustive complete assignments of two unconditional labels and all ordered pairs of a fixed equation catalogue. The oracle must not call graph dereferencing, context algebra or equality. Compare surviving assignments and complete joint values after both equations, with shared aliases normalized jointly.

Validate tests and replay, Clippy with warnings denied, and formatting with a 60-second bound per process. A cutoff is unfinished validation. Record commands, exit codes and source hashes. No test timing is architecture evidence. Remaining source matching, propagation, progress, safe publication and lifetime gates remain required before costs can be compared.
