# Equality controls: registered lifecycle pilot

Register before comparative execution. The source/work gate in S10-equality-invalidation-gate.md finds complementary benefits from same-root detection and syntactic elimination. Determine whether these survive preparation, changed queries and owner disposal. This could change attribution of the prior equality-reset penalty. Support-aware conditional joining is the strongest ready alternative; reconsider it after this bounded attribution rather than extending equality refinement automatically.

H1: same-root detection reduces reset/dynamic execution costs for eager and resumable matching. H2: source elimination additionally avoids constructor creation/queue work but pays rule cloning and traversal. H3: meaningful changes and mixed sources can erase benefits; restarting demand may not benefit from preserved matches. H4: retained answers can dominate peak costs independently of discovery.

Cross four modes (Scan, contextual eager, demand, resumable), six families (stable_history, reset_history, constructor, dynamic, delayed, independent), n=0/3, reuse=1/4, query/prepared consumer, original/eliminated source and conservative/precise builds: 768 cells. Stable/reset sources have 16n items. Constructor replaces the reset equation with box(X)=box(X). Dynamic has 16n consumed alias constraints that bind distinct unknowns to query-specific atoms, then 16n propagation items whose X=Y equations become redundant. Delayed and independent are existing mixed-source controls with meaningful binding changes and choices. At n=0 the dynamic alias work is absent; this is an overhead control. The prior partial-decomposition and guard source gates remain correctness evidence, not an additional timed family.

Each cell runs twice with requested-allocation metering, seed 7820 (1536 processes), then five times with ordinary allocation, seed 7821 (3840 processes). Every memory reading must exactly replay before timing starts. Total 5376 processes. Freeze registration, runner, source/dependency files and four executable hashes; record toolchain and randomized execution order. Bounds per process: 1 GiB address space, 60 CPU seconds, 75 wall seconds; 500,000 service calls per complete query. Any failure/cutoff stops the run for diagnosis and is not classified as an architectural loss.

All builds use release, no default features, experiment and selective-discovery (an inherited runner assertion); precise builds additionally use equality-invalidation, meter builds additionally alloc-meter. Engine/kernel metrics and local-work counters are disabled. Same-root feature forwarding is recorded in Cargo.toml. No conditional engine is in this matrix.

Measure source analysis separately: original retains the caller's rules, eliminated clones/traverses into an owned rule vector. Release the transformed input within preparation once the engine owns its prepared representation; charge that release in preparation. Then charge preparation, input construction, setup, first delivery/exhaustion, remaining delivery, search disposal, answer policy and input disposal for each changed query. Include one-service cancellation and all prepared/retained-answer disposal. Query consumers release each query; prepared consumers retain answers across queries until preparation is dropped. This is bounded retention, not sustained lifetime. Execution and observation remain coupled in delivery. Original AST construction, process startup, native compilation and validation are excluded.

Independent hand-constructed complete observations and the scalar evaluator validate every source/query outside measured intervals. Check warm candidate and all measured answers; retain multiplicity and aliases. Check retained answers again after preparation is dropped. Meter self-check, adjacent-phase continuity and query/cancel/prepared/final owner restoration must pass. Requested bytes are not RSS.

Report pointwise traffic, peak, source-analysis costs and five-sample timing median/range. Timing is exploratory, without practical-win classifications or clock subtraction.
