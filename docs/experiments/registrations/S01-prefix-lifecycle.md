It measures the current qualified implementations, not an intrinsic architecture bound.

## Hypotheses and controls

H1: Proper intermediates can repay setup on deep repeated matches, while cheap prefixes and early consumption expose maintenance overhead. H2: Active native indexed execution may erase the total-cost advantage despite doing more structural tests. H3: Releasing versus retaining answers changes peak ownership and can change the practical comparison. These are conditional hypotheses; no workload weights or universal winner are specified.

Use existing local scan, partial joins and proper intermediates; conventional Global Scan/Indexed; Global generated-access Indexed; Active generic Indexed and Active generated-access Indexed. This is eight modes: `local-scan`, `partial`, `intermediate`, `scan`, `indexed`, `native-indexed`, `active-indexed`, `active-native-indexed`. Full-tuple storage and ineligible inferred specialization are already bounded controls; neither is needed to represent a stronger competitor in this pilot.

Four exact shared source families: sparse, keyed, kill, miss. Depths 0 and 32; widths 4 and 8; query reuse 1 and 4; immediate and retained-all consumers. Family strings encode depth as `prefix-FAMILY-DEPTH`. Query seeds are the integers from zero to reuse minus one. Rules and queries are constructed separately from the same source definition; input generation must not rebuild and discard rules inside the query interval.

Active/kill is excluded from same-answer costs because it changes rule competition. Its independent semantic counterexample remains in the prior evidence. The kill family therefore runs six modes; the other three run eight. The total is 480 cells: (3×8+6)×2 depths×2 widths×2 reuse×2 consumers. Miss at depth zero has absent middle facts, not a matched shallow negative term. Do not infer a depth slope for that control.

## Analysis and interpretation

Reconstruct completed total requested bytes, peak heap above source baseline, preparation, execution/observation/disposal contributions and complete lifecycle time from raw phases. Require deterministic normalized allocation repeats and contiguous phase ownership. Report retained consumer bytes after producer disposal separately from preparation and execution. Compare proper intermediates with local scan, partial and the strongest qualifying compiled controls; report adverse regimes and crossovers.

Five timing samples are exploratory sizing. Use within-block ratios, median and full observed range. A 10% difference is a practical prompt for consequential follow-up, not significance. If a total is below 100 times the maximum median empty-clock cost times its phase count, mark it instrumentation-sensitive. Do not silently drop samples. Confirmation repetitions must be chosen prospectively from observed variability if the result can affect an architecture choice.

A loss dominated by an avoidable implementation cost requires attribution when a sensitivity bound shows it could change the comparison. A win needs contrary sources, confirmation and complete-path integration. No allocation count alone selects efficiency, no source gate alone completes a direction, and broader subscriptions, planning and language questions remain unanswered.
