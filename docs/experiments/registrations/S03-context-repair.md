Keep context representation, region partitioning, scheduling, source lowering and publication unchanged.

The hypothesis is that this removes avoidable allocation traffic and reduces graph lifecycle costs, especially when discrimination creates many context operations. A remaining adverse result must still be distinguished from a general graph limitation. Existing exhaustive context truth tables, contextual equality oracle, complete-source gates and runner validation provide the semantic checks; no new observable behavior is intended.

Preserve the original binaries and freeze from `s03-lifecycle`.
