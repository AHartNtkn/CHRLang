# Existing call reuse at the finite-learning boundary

This is a semantic applicability experiment, not a timing comparison. T075 tests whether the existing call table can supply a credible control for finite failure learning without implementing another cache.

Compare the original ordered phase containing two finite domain producers and one pair check with a single bundled call that posts those same three goals in order. The bundle carries both domain tags and both interface variables. Nine fixed entry rules cover domain masks 1, 3 and 7; all seven original domain producers remain. Bundle rules precede the original private phase. The consuming caller remains outside that phase.

Freeze before execution: accepted pair masks 0, 484 and 511; deterministic prefix depths 0 and 4; duplicate choice weights 1 and 2; domain pairs from {1,3,7} squared; independent versus aliased variables; query variable bases 10 and 1000; memoization off and on. This is 864 complete query comparisons. Reuse one prepared caller across the 36 queries in each source/memo configuration. Change caller markers with query identity. Validate full outputs and residuals against the independent scalar interpreter; independently check weighted answer counts by enumerating the nine ground pairs.

Adverse checks: original multi-occurrence entry is rejected; independently expanding the unbound pair call yields failure even when the whole source has successes; a zero service bound must not install a completed cache result, and a later adequately bounded query must still complete correctly. Existing fresh-output and broader source-order counterexamples remain required companion regressions.

Interpretation: complete agreement qualifies only this explicit finite bundle transformation. A mismatch requires attribution to ordering, aliasing, multiplicity or transport. A successful bundle does not establish arbitrary multi-call contraction, resource-capacity applicability, timing gains, cancellation latency or a general source checker. Domain tags must participate in keys; changing them cannot reuse a different domain result. Source construction, the extra entry rules, preparation, key formation, replay and retention must be charged in a subsequent lifecycle comparison.

Run default and metrics-off tests and Clippy. Bound each test process at 120 seconds. Each engine query has a 200,000-step service bound. No comparative timing or allocation runs are authorized by this registration itself; those require ownership qualification and a separate prospective matrix.

Selection: this is the concrete missing competitor for the measured learning regimes. Broader resource phases are the strongest ready alternative and require a new effect correspondence. Reconsider both after this applicability gate, before a larger cost campaign. This is the first experimental package following the sequence revision.
