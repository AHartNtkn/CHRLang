# Connected term projection: complete cost pilot

Registered before comparative runs. Compare the repaired counted term projection
with the existing early-filtered, weighted enumeration control. Both start from
one finite term-region source; numeric lowering for enumeration is charged to its
preparation. No new solver is introduced.

Hypothesis: eliminating hidden coordinates helps when many witnesses survive,
while dense scopes and selective predicates can favor early-filtered enumeration.
Duplicate alternatives and output aliases must preserve exact weighted answers.

Matrix: modes projection/enumerate; families equality-star, equality-clique,
different-star (unequal names); sizes 4/6; duplicate a absent/present in every
domain; repeated first output slot absent/present; 1/4 changing queries
(unrestricted, a, b, unrestricted); retain none/all; complete/cancel after first
weighted tuple. 384 cells. Domain a/b/c is a fixture, not a language restriction.

Validate complete answers against independent full choice enumeration before each
session. Check measured complete/prefix tuples outside clocks. Reuse preparation;
keep outputs alive after producer disposal in retained cases. All sessions charge
source construction, preparation including encoding/order/relation construction,
source disposal, query input/setup, first tuple, remaining tuples, engine/input
disposal, prepared disposal and consumer disposal. Ordinary builds disable all
metrics and allocation instrumentation. Meter runs use the requested-allocation
meter separately, two exact repetitions per cell; verify allocation ownership
restores and identical consumer ownership across modes. Meter timing is unused.

After ownership qualification, run ten shuffled blocks, one ordinary process per
cell per block (3,840 sessions). Fixed seed 607091. Store every process output,
command, return code and frozen input hashes. No exclusions or retries into the
same result. Per process: 1 GiB address space, 30 CPU seconds, 45 wall seconds;
100,000 projection operations and the existing 5,000,000 enumeration step bound.

Primary comparison: complete phase-sum time, projection/enumerate, paired by block.
Qualified gain requires median <=0.90 and all ten ratios <1; loss median >=1.10
and all ten >1. Other cases unresolved. Both medians must exceed 100 times the
per-process median of 1,000 empty Instant intervals; otherwise clock unresolved.
Report allocation totals, absolute retained peaks reconstructed across all phase
readings, and consumer bytes separately. Compilation is not measured; no full
architectural lifecycle superiority follows. Investigate consequential results
before choosing sparse traversal, ordered transport or another research direction.
