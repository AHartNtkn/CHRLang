# Useful symbolic union: denotation, representation and source qualification

Test the existing reusable diagram union on substantive overlapping finite relations. This package establishes eligibility, exact answers and representation/work bounds. It does not time competing architectures or introduce a new baseline.

The structural-prefix portfolio review selects this investigation because union may replace enumeration of alternatives, whereas retained joins reuse work within execution. Existing formula timing used sources reducible by the current simplifier; here all coordinates are observable and constraints remain substantive after reduction. No hidden projection claim follows.

Use three atomic names, widths four/six/eight, and four families: the union of cycle graphs each missing a different edge; two disjoint three-colorable graphs whose combined constraints contain K4; repeated identical cycle alternatives; and a single cycle. Connect additional variables by a chain for the disjoint family. The independent denotation is the set of complete assignments satisfying every disequality in at least one branch. Record how many branches accept each assignment separately.

For every complete assignment compare diagram union, separate diagrams with early acceptance, the existing graph simplifier, prepared name formulas and direct branch checks with early rejection. Do not force explicit execution to enumerate every hidden assignment: there are no hidden coordinates, and every assignment here is a requested membership result. Exhaustive requests establish correctness, not a realistic workload weighting.
