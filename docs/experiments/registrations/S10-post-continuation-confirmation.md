# Confirm complete-path reversal and counting overhead

The complete lifecycle pilot suggests counting changes the relative standing of demand and explicit execution. Confirm that consequential result using the same frozen ordinary binary, without changing implementation, source or endpoint. This registration precedes the confirmation runs; its cases are selected from the pilot and are not held-out evidence.

Use 39 contrasts. For each common/independent/early source at choices3/depth16/history=true/original arrival/retain-all, compare each of birth, birth-miss and birth-miss-template (counted) with each of native-scan, active-native-scan and sealed-scan (counted): 27 contrasts. On the same three sources compare counted/original for birth-miss, conditional and native-scan: nine contrasts. Finally compare counted/original for those three modes on common choices0/depth0/history=true/original arrival/retain-all: three overhead contrasts.

Run one excluded pair per contrast and 64 measured pairs per contrast: 5,070 processes (78 warmups and 4,992 primary). Shuffle contrasts independently per repetition and shuffle the two configurations within every pair, seed781042. Pin CPU0; 60-second wall/CPU, 1GiB address-space and 10-minute campaign limits; 2,000,000 service operations. Stop on failure and preserve every observation. Do not discard outliers.

Use paired total-phase-time ratios, candidate/control. For each contrast the median interval is the 19th through 46th ordered ratios of64 (zero-based indices18 and45). Under independent samples from a stable distribution, the union bound across39 intervals is below0.05: 78×sum(C(64,i), i=0..18)/2^64. Report that assumption explicitly. A practical gain requires the entire interval below0.90; a loss requires it above1.10; an interval wholly inside[0.90,1.10] resolves only practical magnitude. Other results remain uncertain. Report directional intervals separately from the10% criterion. Retain first/last-half medians and all ratios.

Retain the pilot's43,200ns total signal floor. Any pair member below that floor makes its contrast signal-limited. Confirm complete outcomes and binary/source hashes against the parent pilot. This measures the same finite four-query lifecycle, with preparation, transformations, execution/owned observation and disposal; it does not add native compilation, process startup or sustained service.
