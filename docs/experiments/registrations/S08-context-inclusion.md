## Native operation sizing after semantic entry

Measure the same 51 support/context configurations with ordinary usize keys, both algorithms in one release test binary. For each configuration run nine closely interleaved pairs of 20,000 calls per algorithm, alternating algorithm order by configuration/rep parity. One 2,000-call warmup per algorithm/configuration is excluded. Input maps are built before the intervals; black-box map references and returned booleans prevent result hoisting. Check the result count outside each interval. Report median paired ratios and ranges with the 10%/all-pairs-same-side practical criterion. CPU 0, 60-second CPU/wall and 1 GiB process bound.
