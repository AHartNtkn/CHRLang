# Local claims: bounded atomicity and source-order experiment

Test whether occurrence-local exclusive acquisition, validation and commit can replace the serial source-priority owner. This is package one after the continuing-service breadth review. It is a finite protocol experiment, not native source correspondence or parallel performance evidence.

Use two or three one-shot applications over up to three occurrence identities and one monotone equality-enable bit. Scenarios: disjoint consumption, one shared consumable, overlapping two-head consumers, a kept-head reader versus a consumer, a binding writer that enables an earlier contender, and initially enabled equality. Every successful application publishes one labelled effect atomically with consumption and its optional binding update. The observation is remaining occurrence identities, binding and the bag of committed labels. Ordered residual insertion, fresh identities, branching and nonmonotone guards are outside this model and remain source-integration obligations.

Compare a local protocol acquiring all kept/consumed identities exclusively in identity order with a serial-priority admission control over the same protocol. Local acquisitions and cancellations are individual transitions. Commit is a per-application atomic descriptor decision: its logically visible effects occur together; physical multi-owner publication is an explicit unimplemented obligation. Do not claim this assumed decision already implements native distributed commit. Revalidate resource presence and equality before committing. Cancellation before commit releases every held identity; cancellation after commit cannot undo an effect.

Independent atomic models contain no locks/acquisition phases: one admits any enabled application, the other only the earliest enabled source application. Both admit cancellation of the designated application before its commit. Compare every protocol terminal observation with its appropriate model. Record when unordered execution differs from source priority instead of treating it as an equivalent language. The priority control permits acquisition only by the earliest logically enabled application; it deliberately retains global selection and measures no speed.

Enumerate all reachable states/actions by BFS for each scenario, each designated cancellation target (none or one application), and both protocol modes. Finite limits: 200,000 states per cell, 2,000,000 across the run, 60 seconds CPU/wall, 1 GiB address space. Freeze inputs/source hashes before enumeration. Preserve shortest counterexample traces. Check locks have unique owners, consumed resources never reappear, committed applications hold no locks, cancellation releases partial ownership, and all reachable states can reach a terminal state. A reachable nonterminal state with no successors is a deadlock failure. This reachability test is not a proof of fairness or starvation freedom under arbitrary infinite schedules; the bounded protocol has no retry/self-loop action, so separately verify its graph is acyclic.

Require terminal observation equality with the independent model, not just subset membership, so hidden serialization cannot silently remove permitted unordered outcomes. Count partial-acquisition cancellation witnesses and multiple distinct effects on disjoint resources. A failure requires diagnosis; a passing abstract model requires source-correspondence, physical commit/publication and lifecycle implementation before architecture conclusions. Inspect different-priority observations as language evidence, not implementation speed. Reassess adaptive costs and broader local integration at this gate or an obstruction.
