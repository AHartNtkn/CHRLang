# S03 direct graph kernel: prospective semantic experiment

This experiment tests whether demand-driven named terms and context-local resource consumption can coexist without copying a complete state for each alternative. It is a prerequisite for a source executor, not a source correspondence or performance result.

The candidate stores immutable unknown, constructor and named binary-choice nodes in an arena. Constructor access exposes only the demanded root. Repeated access to a choice uses the same dynamic label; independent births receive different labels even when both arms have equal values. A birth records the earlier choices under which it exists. Complete raw observations enumerate active births, including choices absent from output roots, without assigning inactive births.

A context is a sparse conjunction of label selections. Resource availability is a disjoint union of contexts. An atomic multihead consumption intersects the requested context with every distinct occurrence's availability, then subtracts precisely the successful regions from all consumed occurrences. Distinct occurrences with equal values remain distinct. Late requests intersect current availability and cannot repeat a consumption already performed in an overlapping context. This design introduces region intersection/subtraction and dynamic-birth ownership; it does not yet solve equality, matching, scheduling or source completion.

Before implementing behavior, test these hypotheses: repeated uses preserve correlation; independent choices form a product; inactive nested births do not inflate multiplicity; equal arms and off-output births preserve raw alternatives; opaque constructor access does not enumerate its children; competing consumers partition a resource; multihead failure consumes nothing; late contexts see exactly remaining resources. Test context algebra against independent exhaustive Boolean assignments for four labels, including contradiction, containment, disjointness and subtraction coverage. Compare resource scripts with per-assignment sets of available occurrence IDs. These scalar oracles must not use candidate context algebra to derive their expected results.

Run the kernel tests, a replay and Clippy, each with a 60-second process bound. Bounds reached mean unfinished validation. No timings or allocation results from this gate support an architectural ranking. Record exact commands and source hashes. Source execution must subsequently pass the already registered compound source gate, conflicting consumers, aliases/cycles, late contexts, disconnected failure and finite-sibling publication. Until then T062 remains active.
