Selected after R02's corrected representation comparison. The missing ordinary source-search control blocks a credible comparison of R04 solver elimination and R03 direct conditional execution. Native arc-consistency versus support-CNF learning is the strongest ready alternative; it can compare finite backends but cannot yet rank eliminating ordinary execution. This gate therefore establishes the shared control first, without comparative timing claims.

Implement source binary OR in generic and emitted native bodies. A split inherits the complete pending conjunction continuation, values/bindings, live occurrences, history, indexes, activation state and fresh-variable supply. Prepared rules are shared immutably; initial branch storage is copied. FIFO finite service ensures a finite sibling can progress beside recursive work. Competing rule applications do not create implicit OR. Publication requires a successful terminal branch. Successful raw completions are delivered even when observations coincide; deduplication is a separate observer responsibility. Counter-free runs expose the same operational completion/split/failure events.

The alternative storage designs—persistent overlays and trailing/replay—remain possible later controls. Do not claim copying is the best storage policy from this gate. Its full storage/clone/disposal costs must be included before performance interpretation. A single branch explicitly reports pending split; it cannot publish an OR as a complete answer.
