# Return to integrated equality, matching and consumption

Select T072 precise dependency repair as the next bounded package. The reunion pilot now establishes the intended comparison against executable specialization and elimination controls. Integrated execution has a known avoidable cost that obstructs a credible comparison of a distinct organization.

## Why this can change the architectural decision

The [local pattern gate](S02-local-pattern-gate.md) derives nested, repeated-variable consuming matches from source. Its broad alias witness reinspects requests 2,207 times at width 64, compared with 128 in the narrower gate. Constructor waiting and equality waiting need different wake conditions: descriptor-free aliasing need not recheck a constructor test, but equality of two unknown inputs can enable a repeated-variable match. Treating both as every-merge subscriptions causes avoidable work.

Repair that distinction while preserving nested wakeups, nonbinding matching and consuming order. This could make local equality/matching integration competitive without the same service boundaries as a dedicated matcher. The required evidence is direct: unaffected constructor waits avoid the broad reinspection, while late repeated-variable equalities still wake and complete answers remain independently correct. The existing 200 pattern configurations and broad witness make a bounded attribution test ready.

The current reunion data has both favorable and adverse evidence; another timing matrix on the same finite families cannot resolve the missing general source and lifetime questions. The next package addresses a different architecture's concrete obstacle rather than refining the easiest incumbent measurement.

## Entry, boundary and follow-up

Register the causal dependency distinction and adversarial cases before implementing the repair. Preserve independent scalar answers, constructor consistency, occurs checks, repeated variables, aliases, source occurrence consumption and subscription release. Test both descriptor changes and identity changes at nested positions; do not suppress wakeups merely to reduce a counter.

At the repair boundary, compare extending the integrated executor to complete consuming sources against broader dynamic reunion and source-derived elimination. A successful local repair is not a timing result and does not complete T072. An unsuccessful repair must distinguish a semantic dependency from the representation's bookkeeping cost. The next complete-cost comparison requires ordinary allocator/counter-free paths and equally capable source controls.
