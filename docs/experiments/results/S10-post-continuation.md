# Complete mixed paths now exercise both sharing and elimination

All compared paths now execute the mixed sources, including demand with static propagation initialization and source-derived counting. Counting eliminates the common traversal that conditional execution otherwise shares. The next experiment must measure the full paths, because their preparation and remaining execution duties differ.

## What the source makes each path do

The source combines binary choices, a fuel-consuming traversal, a kept permit, nonground token production and consumption, and a fresh result shared with a residual fact. The token producer posts its output before binding it; the consumer must use that eventual binding. The history-bearing variant propagates one mark per permit occurrence. Independent work adds traversal steps for each b alternative; early failure rejects the first b alternative.

The gate varies three families, choices 0/1/3, depth 0/4/16, two arrival orders, history absent/present and two changing query identities: 216 configurations. Independent analytical answers include every alternative, duplicate fuel occurrences, unused fuel, the mark and fresh aliases. The independent scalar checks the same complete observations and traces source applications.

The shared work is real, and the stronger control removes it. Token production, consuming claims, fresh results, source alternatives and residual fuel still execute correctly after counting. It is therefore insufficient to rank the architectures by avoided traversal applications. Preparation, source transformations, remaining discovery, answer construction and disposal can determine the complete cost.

These are diagnostic source-step counts. No ordinary-allocator timing matrix has run for this source, and no speed ranking follows from the table.

## Repairs make the experiment executable

**Inert query facts now have the correct owner in demand execution.** The prepared call signatures identify calls; other query constraints remain passive resources. A dedicated regression checks duplicate inert occurrences and output aliases against the scalar and compiled execution across demand policies. This removes the need for a dummy source rule merely to admit an inert query fact.

**Static propagation is handled by a source-derived preparation pass.** A nullary propagation head that cannot be created or consumed during execution can initialize inert nullary body facts once per matching query occurrence. The pass checks those conditions from rules and constructs facts from actual query multiplicity. Independent tests cover zero, one, two and four occurrences and reject interfering producers, consumers and observers. The original history-bearing source is the correctness authority; demand executes its transformed rules/query and returns the same complete answers.

**Closed value choices become fresh-output producers for demand preparation.** This syntax transformation gives the demand executor its required producer representation while leaving choices in the source-level comparison. It chooses fresh predicate names from the actual rule vocabulary. The transformed source is independently executed by the scalar as well as demand for every matrix cell, before and after counting. This gate qualifies those source transformations on the registered sources; it does not adopt a language restriction or assert a general compiler theorem.

**The fixture now exercises the counting control rather than ending at its entry test.** Nonground token production and consumption occur in the traversal terminal. The source still exercises common versus branch-dependent work and failure, and the existing compiler can derive removal of the common depth. Inference and query lowering are required to succeed in every cell. Original and counted forms are checked through all paths, rather than substituting analytical answers for execution.

The [registration and repair amendment](../registrations/S10-post-continuation.md) retain the initial experiment, exact matrix and corrective work. Initial attempts and their source snapshot remain diagnostic records; the final frozen source and final logs support the result above.
