# Interrupted queries release their state and preparation remains reusable

All 544 interrupted query lifetimes restore their diagnostic live-byte baseline. All 544 following changed queries match independent scalar source execution using the same prepared rules. The runner now accounts for interrupted execution separately from completed answers and for artifact disposal separately from runtime phases.

The [prospective gate](../registrations/S01-cancellation-artifact-lifetime.md) establishes ownership and measurement boundaries. It makes no cancellation-speed or architecture ranking.

## Interrupted execution is an explicit endpoint

An optional service budget interrupts even-numbered queries; odd-numbered queries run to completion. The interrupted rows contain no validated-answer claim and report whether execution had already exhausted. Setup, serviced work and engine disposal have separate measurements. No observation is requested for an interrupted query.

Across payload's seven modes and subscription's ten modes, sizes zero and sixteen, budgets zero and three, ordinary/metered builds and two repetitions, all 272 processes complete. None of the 544 interrupted queries had exhausted at its endpoint. All subsequent queries validate complete outputs, aliases and residual multiplicity against the independent oracle.

Each diagnostic query and prepared lifetime restores its starting live requested-byte count. All 68 diagnostic configurations replay identical phase readings. This checks both disposing pending work and preserving preparation for later queries. Equal service budgets do not imply equal source work across these engines; the counts cannot support a cross-engine cancellation ranking.

## Artifact lifetime has a distinct accounting boundary

Source generation, compilation and process execution have separate receipts. Once all users of an artifact have exited, filesystem disposal calls have their own measured intervals and endpoint checks. The shared runtime remains reusable and is outside per-ruleset artifact disposal. Content hashes and emission/compilation commands preserve reproducibility.

This endpoint measures host filesystem syscall time. It does not include a durable-storage synchronization requirement or establish when the kernel reclaims cached pages. Runtime phase totals likewise exclude process startup and exit. A total-cost report must state these boundaries instead of adding an unmeasured teardown assumption.

The [validation receipt](s01-cancellation-artifact-lifetime/validation.json) rechecks every process, allocation replay and lifetime endpoint. The [source freeze](s01-cancellation-artifact-lifetime/source-freeze.json) identifies the runner, meter, existing engines and independent oracle. Both ordinary and diagnostic emitter/library configurations pass strict Clippy.
