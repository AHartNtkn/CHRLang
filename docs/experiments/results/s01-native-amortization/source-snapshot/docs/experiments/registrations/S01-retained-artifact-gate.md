# Retained source controls at the artifact boundary

Integrate the existing subscription indexed, eager-retained and demand-subscribed
engines into the shared artifact runner, preserving its exact subscription source,
query inputs, phase boundaries and independent scalar oracle. The new modes must
reject unsupported source families. No native artifact may impersonate a retained
mode. This is source/accounting validation, not comparative timing.

Validate all ten modes on subscription sizes 0, 8 and 32 with four changing queries,
under ordinary linking and ThinLTO: 60 processes, 240 queries. Rebuild the shared
counter-free bitcode runtime and affected generic/subscription artifacts in a new
target. Include unsupported-family, native/mode mismatch and existing ruleset
mismatch rejection. All runs must exhaust and match complete independent answers.
Run the existing subscription source semantic tests to cover consumption, aliases,
failure, cancellation and update sequences beyond this artifact source.

Limit each build/compile to 60 seconds and 4 GiB address space, each run to
60 seconds and 1 GiB, each query to two million source steps. One repetition is
required; no comparative cost inference. Reject inconsistent phase totals or
partial output. Preserve source/binary hashes and commands. Allocation and new
cancellation measurement remain subsequent accounting work; existing correctness
tests do not establish their cost.
