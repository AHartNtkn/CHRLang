## Selected T059

Use T056's same-source before/after discrimination, successful aliases and clash
outcomes, a few term sizes and preparation reuse. Compare Conditional, Specialized
and Specialized+COW; the ordinary explicit control prevents an adverse mutation
cost from being hidden by selecting COW alone. Charge source construction,
preparation, query setup, complete service/observation and disposal. Separate
ordinary-allocator counter-free timings from allocation/work diagnostics.

The explicit path must conserve its16 failed leaves. Conditional exposes whole-query
exhaustion rather than the same per-leaf publication API; report that distinction
instead of asserting API equality. E12 preserves actual equation boundaries and
shows an owned-term cache can lose despite hits. E15's grouping result concerns
identical states, not equality across distinct choice assignments. Neither supplies
the missing current cost evidence.

If Conditional loses or overlaps, this source supplies no additional adoption
reason. If it wins, report a bounded current-engine advantage and then assess
whether a branch-preserving shared-representation cache could change the decision
enough to justify its certificate, dependency, cache and replay machinery. Do not
claim intrinsic necessity or require every imaginable optimization beforehand.
Register exact cells, repetitions, controls, caps and interpretations before runs.
