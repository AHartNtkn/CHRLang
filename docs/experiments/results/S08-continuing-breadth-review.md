The strongest ready alternative is adaptive separation's ownership/cost comparison. It already has a source gate and can expose a useful policy crossover at relatively low implementation cost. Local claims receive the next package because they could change a central execution responsibility and the feasibility of connected parallelism; another scheduling measurement cannot answer that question. This is a priority judgment, not a result against adaptation.

## Why change direction at this boundary?

Four packages have now examined sustained service: consumer-pressure qualification, the incomplete ownership preflight, conditional service attribution, and continuing reclamation/process-budget qualification. Correctness and attribution packages count toward breadth even without a timing matrix.

The resource witness establishes that reclamation can operate during continuing execution, whereas the pure source provides a real no-opportunity control. Conditional service costs and growing graph owners still need investigation. Their next steps include representation attribution and potentially substantial repairs; continuing those automatically would postpone a distinct architectural question again. Preserve the bounded evidence and return to those obligations at the local-ownership gate or an obstruction.

## Bounded local-ownership entry

Begin with disjoint consuming applications and two applications contending for one occurrence. Add a kept-head reader, an equality-enabled contender and cancellation after partial acquisition. Enumerate bounded action interleavings against an independent atomic transition model. Check single consumption, no partial body publication, release of abandoned claims and progress after cancellation under explicitly fair schedules.

State the source-order contract before implementation. Compare permitted committed effects against the existing serial source semantics; if a protocol admits additional winners, report that as a language difference and test the corresponding alternative explicitly. Do not force arbitrary internal schedules to match, or validate only lock ownership while observable CHR effects differ.

Compare a concrete local acquisition/validation/commit protocol with the serial owner. Identify retained state, version checks, contention handling and cancellation responsibilities. Preserve branch correlation and occurrence identity. An abstract interleaving gate is a prerequisite: it must later drive actual source execution before it supports architecture or scaling claims.

Register the finite state/action bounds, scenarios, independent model and failure interpretation before enumerating. A counterexample requires a causal repair or a scoped impossibility argument; a passing bounded model requires source integration and adverse cases next. Reassess adaptive costs, conditional equality, richer theories and broader reuse at that gate or a consequential obstruction. This starts a new breadth cycle, with another full review after at most four packages.
