# E10 first structural services receipt

The closed-operation and bounded constrained-space probes pass their independent checks and full replays. Operation memoization saves repeated proof traversal when immutable input identity repeats; regular intersection avoids enumeration in selective or empty spaces. Neither wins uniformly. These findings keep structural services viable without selecting a production architecture or closing E10.

## Reproduction and validation

Registration: [E10](../registrations/E10.md). Operation source freeze `8cc6701`; space source freeze `41f08c7`. Rust 1.97.1, Linux x86_64. Build each example with `cargo build --release -p chr-structural --example operation_probe` or `--example space_probe`. Run `python3 research/chr-structural/run_operations.py OUTPUT.tsv` and `python3 research/chr-structural/run_spaces.py OUTPUT.tsv`. Each configuration runs in a fresh process with a 60-second limit. Timing is diagnostic; allocated payload is not RSS.

[E10-operations.tsv](E10-operations.tsv) and [replay](E10-operations-replay.tsv): 150/150 passing configurations in each, no non-time field differences. [E10-spaces.tsv](E10-spaces.tsv) and [replay](E10-spaces-replay.tsv): 270/270 passing configurations in each, no non-time field differences. No timeouts. Expected construction/checking occurs outside measured intervals.

Nine structural tests cover 3,192 no_c trees against the independent reference in both modes, residual multiplicity and unknown constructors, invalid external observers, regular intersection on generated automata, finite witnesses, independent versus equated holes, and eight finite skeletons against explicit CHR generators in all three modes. Constructor-generated ground spaces independently validate measured prefixes and cardinalities. The reference interpreter does not import these algorithms.

## Closed operation

At depth 12 with 64 roots, the shared ground tree requires 524,224 Direct node computations versus 13 Memo computations. Direct allocates no reduction storage; Memo allocates 1,464 bytes. Failure on the first left spine requires 13 computations in both modes, with the same memo overhead and no hits.

The unshared ground control requires 524,224 computations in both modes, with no memo hits. Memo adds 41,038,344 bytes of reduction allocations; absolute peak payload rises from 38,274,158 to 79,307,500 bytes. Avoided traversals cannot be inferred merely from tree shape.

Repeated holes preserve 262,144 residual occurrences. Reduction allocations fall from 31,424,512 to 6,391,184 bytes, but full export allocates 26,214,476 bytes in both modes. Retained memo results slightly increase peak payload. Proof reuse does not compress the source answer contract. unknown(c(z)) remains residual, rather than being rejected by recursive membership.

The input identity is retained strongly in each memo key. These are frozen reductions, not mutable-variable wake-up services. The four-rule certificate rejects external consumers/observers; relaxing that boundary requires a separate semantic argument.

## Bounded spaces

At four hole occurrences and node bound nine:

| Restrictions | FilterFirst compilation bytes | FilterSmallest compilation bytes | Intersect compilation bytes |
|---|---:|---:|---:|
| Independent N holes | 402,735 | 402,735 | 402,995 |
| N, HasK, K | 827,230 | 1,388,842 | 72,890 |
| HasK, S (empty) | 1,119,776 | 977,540 | 3,931 |
| HasK, HasS | 1,396,688 | 2,331,488 | 2,213,228 |

FilterSmallest reduces membership work for selective restrictions, but enumerating every domain costs more. Intersection eliminates the empty case before candidate enumeration. In the overlapping case its nondeterministic grammar constructs 3,228 enumeration candidates versus 1,355 in FilterFirst, despite avoiding membership checks. This supports further representation/normalization experiments, not a universal performance conclusion.

All controls merge explicit hole equations first and share candidate lists. Four independent N holes have 91,506,250,000 finite combinations; only the registered first 1,024 are observed. Repeated and merged holes each have 550 answers and are exhausted. Counts are exact products because every equivalence class appears in the skeleton; they are not claims that huge answer sets were enumerated. The single-domain control offers no intersection benefit. Full repeated-hole output alone allocates 1,071,018 bytes, exceeding domain compilation.

## Remaining investigations and disposition

This first package is complete; the direction remains open. Useful feasible follow-ups include reducing nondeterministic automaton redundancy; lazy candidate generation and fair increasing bounds; genuine arbitrary finite path constraints and dynamic ECTA reduction; closure certificates and binding wake-up integration; formula projection with existential variables; lambda normal/neutral/name/disequality theories; and intended type/program synthesis workloads. Current measurements do not justify closing those questions. Regular algorithm correctness has inductive arguments and executable checks, not a kernel proof. The bounded skeleton service is not a general ECTA compiler.

The next independent portfolio package is E11 whole-evaluator symbolic compilation. Its viability does not depend on these structural results. No language contract or production architecture is adopted here.
