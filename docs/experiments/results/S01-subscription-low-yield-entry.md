# Next subscription contrast: expensive discovery with few matches

The initial subscription pilot establishes costs for cheap selective discovery and dense output-producing joins. It does not establish whether subscriptions repay a costly repeated search that produces very few matches. That missing favorable mechanism must be tested before using the pilot to dismiss demand retention.

## A source that distinguishes search from output

Use N left rows `left(k, f(a_i))` and N right rows `right(b_j, h(value))`. Add middle rows from each selected `a_i` to N absent right endpoints, and from N absent left endpoints to each selected `b_j`, plus one real bridge `(a_0, b_0)`. Thus 2N²+1 middle rows support exactly one matching data triple. Repeat pulses under a live demand; vary repetition separately from N and include retirement and updates. Source observations must retain all unmatched data rows and preserve exact occurrence multiplicity.

Both selected endpoint buckets contain N rows. A one-sided traversal encounters many unsuccessful continuations, while retaining the one successful triple can avoid rediscovery. This is a candidate favorable source, not a predicted timing result.

The current control chooses a starting side by endpoint cardinality. A new low-yield case must not exploit that heuristic when a simple better plan is available. The latter uses the existing exact middle index and takes N² point probes on this construction.

Establish a competent source-derived choice among those plans, account for plan selection and its dependencies, and validate its complete answers before comparative timing. If a more selective access path makes the supposedly expensive witness cheap, revise the witness or the claim. Do not report an avoidable access-plan defect as a subscription benefit.
