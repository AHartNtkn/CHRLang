# Substantive pre-discrimination work entry (T056)

T055 supplies a sufficient bounded pure-carrier disposition. The next candidate
question is whether sharing substantive finite-tree equality before discrimination
has complete-path value against a competent explicit control. This is an entry
investigation, not permission to assume arbitrary work is noncontractible or to
start a timing matrix.

The smallest proposed source makes four fresh binary choices, calls
`verify(L,R,tuple)` whose body performs L=R, then discriminates the tuple through
16 constructor-specific gates. Query row terms vary depth and contain repeated or
linked variable leaves; an independent small residual witness must retain tuple
and joint alias information. Success and late-clash outcomes, early discrimination
and separately sized postwork are proposed controls. The equation must contribute
to the expected answer or failure, not merely supply a work label.

## Competent control and exact outstanding gate

Common equality over variables disjoint from the choices suggests factoring before
OR. This is not automatically an equivalent source transformation. The compiled
source correspondence gate requires every split lineage to terminate, including
failed leaves: a pre-OR clash would yield one failure instead of16. Conditional's
successful-answer/exhaustion endpoint does not expose those individual events;
that difference does not silently authorize weakening the explicit gate. The
current mixed runner also rejects failure and cannot measure this fixture unchanged.

Independent review proposes a conservative control: compute equality once against
common bindings without publishing its delta or failure; execute the original
choices; apply the cached delta or cached clash at each ordinary verify. Preserve
choice bindings, joint aliases, original application traces and16 failed lineages.
Its certificate must prove intervening work does not observe or mutate the equation
variables. Speculation, cache ownership and per-branch application must be charged.
Inspect existing E12 equation/continuation evidence before implementing another
cache. Alternatively, a compressed-history contract would require a separate
explicit correspondence gate; it is not assumed here.

T056 therefore first resolves source/oracle and competent-control feasibility.
If this small gate establishes a decision-changing contrast, register complete
costs before runs. If it primarily repeats an already settled cache boundary or
requires broad machinery, prefer a current maintained-join bottleneck screen.
The latter has broader access relevance but needs current evidence before a new
maintained engine. No additional pure-carrier tuning or prototype priority is
selected. The architecture goal remains active.
