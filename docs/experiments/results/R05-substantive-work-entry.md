## Competent control and exact outstanding gate

Common equality over variables disjoint from the choices suggests factoring before
OR. This is not automatically an equivalent source transformation. The compiled
source correspondence gate requires every split lineage to terminate, including
failed leaves: a pre-OR clash would yield one failure instead of16. Conditional's
successful-answer/exhaustion endpoint does not expose those individual events;
that difference does not silently authorize weakening the explicit gate. The
current mixed runner also rejects failure and cannot measure this fixture unchanged.

Independent review proposes a conservative control: compute equality once against
common bindings without publishing its delta or failure; execute the original
choices; apply the cached delta or cached clash at each ordinary verify. Preserve
choice bindings, joint aliases, original application traces and16 failed lineages.
Its certificate must prove intervening work does not observe or mutate the equation
variables. Speculation, cache ownership and per-branch application must be charged.
Inspect existing E12 equation/continuation evidence before implementing another
cache. Alternatively, a compressed-history contract would require a separate
explicit correspondence gate; it is not assumed here.
