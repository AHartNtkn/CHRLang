# Continuing reclamation works; separate budgets qualify the graph run

A consuming continuation gives the existing graph collector a real reclamation opportunity while preserving every checked answer. Separating validation from measurement also lets the previously timed-out dependency configuration complete. Neither result supplies a comparative architecture ranking.

## Reclamation now has both an opportunity and a control

The source emits a fresh aliased pair or continues recursively. The resource variant adds a finish rule that consumes a token before exposing the pair. An independent expected answer specifies both aliased fields and an empty residual store; retained answers are checked again after engine and preparation disposal.

All eight registered source/configuration processes pass, checking 64 answers each. The matrix crosses dependency/template execution, retention/reclamation and pure/resource sources. In both resource/reclamation cells, the collector removes 64 result records and 64 consumption claims. In both pure/reclamation cells it removes nothing. Complete observations remain correct in all cells.

This establishes that the collector's distinctive operation can run during continuing execution. It does not establish that its scanning and shrinking costs repay the released storage, or that other retained graph owners can be reclaimed. Those require allocation and ordinary-allocator cost comparisons with both source variants.

## Validation and measurement both fit their own limits

The dependency configuration with demand 512, retain-all consumers and queue capacity four completes independent replay under a 60-second process budget. A second process then completes preparation, production, pause checks, cancellation and disposal under its own identical budget. Each has a 1 GiB address-space limit. No phase or owner was omitted to obtain this result.

The frozen combined-process timeout remains valid evidence about that harness budget. The new result shows that the combined budget was an obstruction to qualification; it does not imply either phase individually exceeds 60 seconds. No elapsed-time superiority claim follows from passing a resource limit.

Full-queue pauses perform no allocations or producer service. These are requested heap measurements, not RSS. This is one allocation qualification observation, not a repeated matrix or proof of an asymptotic growth rate.

The result makes retained engine state a concrete investigation target. It does not show that this storage is required by graph semantics. The pure source still gives the existing incompatibility collector nothing to remove; resource-source allocation, other reclamation mechanisms and conditional binding/support costs remain open.
