## Consequential follow-up disposition

Root and independent reviewers find a branch-preserving cached clash credible but
not necessary to make this comparison fair. E12 selective failure checking supplies
actual-boundary proof reuse with adverse checking costs, not a universal reuse win.
This source's clash lies down its row spine; validating that path retains traversal.
Cheap reuse would require sound query-local identity or inherited-node validity,
not colliding numeric handles. Source splits/failures must remain, and success
replay introduces additional binding ownership.

That implementation could narrow this common-failure advantage and potentially
strengthen the explicit baseline. It would not refute the observed explicit gains
in successful and post-discrimination cells. No workload distribution makes
eliminating this exception a necessary architecture decision. Retain the measured
current-engine advantage without calling it intrinsic or unavailable to explicit
proof reuse. Close this bounded experiment; no further repetitions or cache
implementation are presently justified. Proceed to full-objective closure audit.
