# Include the existing projected-update data plans

Amendment before interpreting amortization. PreparedRuleset::new_with_update_plan
already applies the generated update projection as ordinary prepared data, without
native compilation. The initial campaign was deliberately interrupted (status130)
when this missing control was identified. Preserve its completed compiler,
qualification and timing receipts; do not pool them into the amended comparison.

Add planned indexed and planned-plus-inferred controls, using that existing
constructor. Extend the shared source gate to five modes:1280 source cases and
3840 cancellation restarts. Validate it with counters enabled and disabled before
comparative runs. No new engine or language restriction.

Otherwise retain S05-call-amortization's four regimes, initial64/8192 query counts,
five compiler repetitions, two allocation repetitions, ordinary qualification,
five randomized timing blocks, clock checks, bounds and accounting. Nine runtime
modes give72 initial cells,144 allocation runs,72 ordinary checks and360 timing
processes. Each generated mode compares with all seven generic/reuse controls:
fourteen comparisons per scenario. Reuse the exact frozen shared libraries and
emitter from the initial build, checking their hashes; repeat per-program
compilation against the common amended runner. Shared dependency construction
stays separate from per-program costs.

For conditional32768-query extension, require a generated mode's median runtime
ratio<=0.9 against Direct, scan, inferred, planned and planned-inferred at8192,
and no installed-runtime amortization gain over any of those five even before
pending artifact-disposal costs. Select the source/mode with largest minimum
median absolute saving across those five controls, with the original tie rule.
Run all nine modes with two allocation, one ordinary and five timing repetitions
if eligible. Final totals include actual disposal.

Report phase-sum totals and a process envelope. The latter uses whole emitter,
compiler and runtime process wall durations, plus artifact disposal; it includes
validation/recording overhead and is not bare execution time. Preserve compiler
and timing uncertainty. The data-plan comparison must inform whether a benefit
belongs to avoiding work, compilation, or their combination before selecting the
next portfolio investigation.
