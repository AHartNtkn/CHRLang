# Generated matching on the live caller sources

Registered before generation/build/run. Reuse `generate::emit_access` and the
existing compiled source gate. Generate from rules only: four caller families,
both branch orders, no query values. Compile the eight descriptors into a fresh
standalone artifact. Keep the source rules as a preparation consistency check.

Run the same 768 combinations (scan/indexed/inferred specialization, four
families, both orientations, independent depths 0/1/4/8 and two variable
namespaces). Require complete ordered answers against Direct, independent scalar
bags, first-answer cancellation, 0/1/5-tick abandonment and 2,304 restarts, and
retained-output checks after preparation disposal. Run counter-free, compiled
metrics and allocation-meter configurations. No architecture inference from mere
compilation or generated source size.

Expose the same lifecycle runner to a supplied generated descriptor rather than
copying its measurement implementation. Before comparative timing, run all 144
existing caller scenarios through generated indexed execution twice with the
allocation meter and once ordinary. Require identical complete answers and
cancellation prefixes, equal final consumer ownership to the preceding matched
campaign, reproducible requested/peak/query-end bytes, contiguous ownership and
root restoration. Include ordinary generated and inferred-generated modes if
inferred preparation changes execution on these sources; verify behavior first.
This adds 288 scenarios and 864 lifecycle runs for the two modes. Keep original
frozen binaries and evidence intact.

Record emission duration and source bytes, build logs, binary bytes and hashes.
These first builds qualify artifacts; they are not a replicated compiler-cost
comparison. Register compiler/amortization and paired runtime controls before
comparative costs. Build each configuration offline with at most two Cargo jobs;
allow 120 seconds per compiler invocation and 100,000 ticks per gate search.
For lifecycle processes use 1 GiB address space, 30 CPU seconds and 45 wall
seconds, as in the matched campaign. Preserve failed receipts and repair their
cause before progressing.

Decision: generated selection can change whether trace reuse remains worthwhile
once source matching is optimized. If generation reveals an observation mismatch,
fix that boundary before costs. After qualification, compare complete runtime and
compiler costs before choosing bounded retention versus broader interleaving;
sparse projection and other portfolio work remain independent obligations.
