# Demand gains survive stronger post controls, with substantial adverse cases

Actual generated access and Active scheduling reduce several explicit costs, but do not erase the favorable demand regimes in this pilot. Demand with miss reuse has a median time ratio below0.90 against all nine explicit controls in50 of72 scenarios. Large unsuccessful matches remain much slower and allocate far more; five repetitions do not establish a general architecture choice.

**Next, confirm consequential favorable and adverse timing comparisons with the stronger controls fixed, then review the full portfolio.** Keep the miss/copy/discovery repair as a distinct required investigation. Do not replace a time–memory tradeoff with an allocation-only ranking.

## Arrival and failures expose the limits

**Original arrival narrows or reverses demand's benefit.** For the same size32 output-post source, demand takes1.059 ms versus generated Global Scan's1.286 ms, while requesting1,614,631 versus932,368 bytes. For duplicate resources, original-arrival demand takes3.368 ms versus generated Global Indexed's2.172 ms and requests4,285,842 versus1,477,882 bytes. Source order remains an architectural sensitivity, not an assumed workload distribution.

**Large misses remain decisively adverse in the observed pairs.** Size32 original-arrival demand with miss reuse takes6.769 ms versus generated Global Indexed's1.141 ms. Paired demand/native ratios range5.268–9.276, with median5.688. Requested traffic is12,259,743 versus878,200 bytes, and peak heap149,602 versus137,698. Reversed arrival also retains the loss. This scopes an implementation problem; it does not prove demand or a different discovery algorithm intrinsically requires these costs.

The existing copy-attribution study identifies expensive environment and argument copying, but no new time attribution follows from those bytes. The primary pilot's optimistic zero-execution bound leaves room for a runtime reversal. Sound delayed/borrowed match state, different candidate discovery and their replacement overhead remain concrete follow-ups.

## Generation and activation earn different savings

**Generated code improves a competitor without guaranteeing the best complete path.** Original-arrival size32 forward posts have a7.424-ms generated Global Scan median,2.177-ms generated Global Indexed median and2.186-ms generated Active Indexed median. Demand with miss reuse takes1.866 ms in that scenario. Choosing access matters more here than merely emitting the same scan as native code.

Activation reduces forward-source candidate discovery in the prior work gate, but increases input/output/duplicate candidate visits. Its lifetime costs therefore need actual measurements. On reversed output posts, generated Active Scan improves over generated Global Scan; on original output posts it is slower. There is no universally preferred activation or index setting in these results.

All original-control normalized allocation phases and endpoints still match their frozen parents. This supports attributing the new comparison to the added controls rather than an unnoticed allocation change in the demand baseline. Timing comparisons use freshly built modes within the same randomized blocks; do not compare separate campaign medians as if they were paired.

## What remains uncertain

For birth, birth-plus-miss and birth-plus-miss-plus-template policies respectively, median ratios are below0.90 against all nine explicit controls in51,50 and49 of72 scenarios. Requiring every sampled pair below0.90 reduces those counts to35,31 and33. Each policy is slower by median than all nine controls in six scenarios. These are descriptive, unweighted counts, not significance or prevalence.

All864 cells clear the registered31,200-ns clock threshold; calibration medians are13,12,12,12,12ns. Individual timing excursions remain, and five repetitions are exploratory. The next confirmation must freeze its source/consumer scope, repetitions, controls and inference before running, retain all samples and include misses and unfavorable arrival rather than only large favorable ratios.

Source, preparation, query input/setup, combined execution/owned observation and disposal count in totals. Compilation, linked code storage, startup/transport, validation and harness containers remain outside. Allocation traffic and tracked live heap are not RSS. First-answer latency is not separately timed, and finite cancellation/reuse does not establish sustained memory behavior.

Demand still owns births, contexts, claims, output dependencies and validity/reuse state. Generated explicit execution removes syntax interpretation and some temporary matcher structures but retains matching, activation, equality and resource ownership. These responsibilities—not line counts or a single microbenchmark—are the relevant complexity tradeoff. Dynamic choices, writable heads, broader source eligibility and complete architecture composition remain untested by these post families.

## Next selection

**Bounded confirmation now has credible controls and can change a complete-architecture decision.** Favorable demand timing survives general generated access and both scheduling policies on the checked contract. Confirm the strongest consequential time–memory cases and their adverse counterparts, keeping simple scanning and both useful native access forms. Do not declare the cheapest sampled mode universal or add a source-routing policy without testing its cost.

Compact runtime confirmation remains the strongest ready distinct alternative. One demand confirmation package is justified because it can establish whether this richer post capability has a stable advantage against the now-qualified alternatives. At its result or a concrete prerequisite/attribution obstruction, conduct the full portfolio review, including compact confirmation, miss repair, integration and call-reuse costs.

The post timing pilot was package one, the native/access gate package two, and this lifecycle comparison package three after the full prefix review. At most one further package may precede full review. No broader mechanism receives a rejection or completion disposition from this scheduling choice; the research goal remains active.
