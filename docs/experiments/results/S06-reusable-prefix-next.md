The [confirmation](S06-reusable-prefix-confirmation.md) establishes practical gains in every long repeated configuration against all five tested alternatives, and many short losses to ordinary execution. It leaves one-shot lowering variants uncertain. Refining those intervals could select a variant for that particular workload, but cannot decide how much source execution a more general compiler can eliminate.

The strongest ready local alternative is artifact preparation under unplanned signatures and sustained retention. It could change the economics of reuse when interface stability fails. Its dependencies are small, and it remains required. However, it still studies the same accepted acyclic transformation. It cannot answer whether recursive derivations, unknown-input matching or resource effects require the current runtime organization.

Broader integrated execution and graph observation are the strongest alternatives outside compilation. ## Required discriminating source gate

Inspect candidate recursive source transformations before choosing an implementation. Require an operational difference from finite prefix unfolding or an exact-schema answer generator. A ruleset-specific executable loop or recurrence must be derived from source, with a clear account of matching, fresh variables, recursion, failure and terminal residuals.

Include a recursive private computation feeding an equality-enabled consuming suffix, plus an input whose required constructor information is initially unknown. Nonbinding matching must not invent that information. Determine whether analysis can preserve suspension and later activation, or whether a proved input property defines an explicit eligible fragment. Record that language boundary and test near misses; do not silently assume ground inputs.

Use an ordinary compiled source control and the independent scalar evaluator for complete terminal observations. Preserve duplicate resource identities, independent alternatives where admitted, off-output failure and the permitted committed source order. Include a competing consumer witness to expose any schedule change from contracting private work. Where finite service applies, demonstrate it beside continuing work.

Compare source analysis, a reusable derived plan and applicable direct controls only after correctness. Charge analysis and preparation separately from query execution, include changed inputs and sources, and register the cost experiment prospectively. A recursion bound is not a proof of general termination or absence of answers beyond that bound.
