**Select T075 and retain T076 as unfinished.** Connected projection now has a
counted source gate, complete costs, preparation attribution and a validated repair.
That repair saves time and temporary allocation without qualifying against the
strong enumeration control. This is enough evidence to change the next priority,
not enough to close projection or the architecture goal.

Whole-call recognition must not merely run a call atomically. The prior
[effectful boundary gate](S05-effectful-boundary-gate.md) preserves complete bags
while changing first delivery in unequal-length branches. The next gate must
retain externally observable source progress, using an explicit replay or resumable
protocol and charging its retained representation. Start with inspectable closed
calls; extend fixtures where they obstruct the question. Reject a transformation
when its tested semantics fail, not the broader research direction.
